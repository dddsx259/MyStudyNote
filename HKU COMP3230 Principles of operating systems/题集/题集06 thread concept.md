## 课件证明

### P1. `x++` 非原子导致丢失更新

- **陈述**: 两线程无同步地对共享 `x` 执行 `x++` (实现为 load-inc-store) 时, 终值可以只增加 1.
- **证明**: 交错: T1 load → T2 load → T1 inc store → T2 inc store, 第二次 store 覆盖第一次, 净 +1. 单核线程切换或多核并行均可实现该交错.
- **来源**: 讲义 §5; OSTEP Ch.26

### P2. 临界区需要互斥而非仅单次原子指令 (自拟)

- **假设**: 临界区含多步更新 (如链表删除涉及多指针).
- **结论**: 把单个 load/store 做成原子不足以保护整个不变量; 需要互斥锁等跨越多指令的临界区机制.
- **来源**: 讲义 §6–7

## 练习题

### 1. 课件选择题: +10 与 −25

- **题目**: 初值 0; A 增 10 次, B 减 25 次, 非原子; 终值范围?
- **思路**: 答案 **C** $[-25,10]$; 见讲义 Exercise.
- **来源**: `Lec07 thread concept` p.20

### 2. 线程 vs 进程切换开销

- **题目**: 为何同进程线程切换通常比跨进程便宜?
- **思路**: 地址空间不变, TLB/页表少刷; 共享资源无需全面切换.
- **来源**: 讲义 §3

### 3. `pthread_join` 与返回值生命周期

- **题目**: 线程能否 `return &local` 给 join 方?
- **思路**: 不能 — 栈回收后悬空. 用堆或主线程缓冲.
- **来源**: OSTEP Ch.27 阅读讲义

### 4. Linux `clone` 与 LWP

- **题目**: pthread 在 Linux 上如何与调度器交互?
- **思路**: LWP + `clone` 指定共享资源; 调度器按可调度实体一视同仁.
- **来源**: 讲义 §4.5
