## Abstract（摘要）

### 梳理

深度卷积网络在图像生成与复原上表现优异，通常归因于从大量样本**学会**真实图像先验。本文主张相反一面：**生成器网络的结构**在任何学习之前就已捕获大量低层图像统计。随机初始化网络可作为手工先验，用于去噪、超分、修复；同一先验还可反演深度表示以诊断网络，以及处理 flash–no-flash。方法桥接「大数据训练的 ConvNet 复原」与「自相似等无学习手工先验」。

### 提取

- 核心主张：structure ≫ learning（就低层统计 / 若干逆问题而言）。
- 应用清单：denoising、super-resolution、inpainting、representation inversion、flash–no-flash。
- Fig.1 叙事：Bicubic（无训练）vs DIP（无训练）vs SRResNet（有训练）——DIP 更接近后者观感。

### 分析

**论文事实**：摘要明确「prior to any learning」。  
**批判性分析**：「excellent / quite close to SOTA」是相对无学习基线与部分 MSE 监督方法的定性概括；正文表中 DIP 仍低于 SRResNet / LapSRN。阅读时把「close」理解为缩小差距，而非全面持平或超越。

## 1. Introduction

### 梳理

SOTA 去噪、单图超分、从深度激活或 HOG 重建、GAN / VAE / 像素误差生成等，都依赖 ConvNet。流行解释是「从大数据学先验」，但不够：随机标签仍可过拟合，说明需要结构与数据「共振」。本文证明：并非所有图像先验都必须从数据学习；生成器 ConvNet 结构已捕获大量统计，尤其适合复原中「退化丢失信息」需由先验补全的情形。

做法：不在大数据上训网，而把生成器拟合到**单张**退化图；权重即恢复图像的参数化；随机初始化 + 任务观测模型。信息源 = 单张退化输入 + 手工网络结构。作者称这是首次直接研究「深度卷积生成网络所捕获先验、且独立于从图像学习参数」。

额外应用：用 DIP 替换 Mahendran & Vedaldi 的 TV 自然先验做 natural pre-image；以及 activation maximization——因先验仍是手工的，避免学习式正则引入的偏差。

### 提取

| 要点 | 内容 |
|---|---|
| 反直觉设定 | 未训练 ConvNet + 单图拟合 |
| 对比对象 | 大数据学习先验；TV 等经典手工先验 |
| 诊断价值 | 反演 / 激活最大化时减少学习正则偏差 |

### 分析

**论文事实**：强调「only information … single degraded input … handcrafted structure」。  
**批判性分析**：引言把 Zhang et al. 分类过拟合与生成先验类比，启发性强但机制并不相同（标签随机 vs 图像逆问题）。课程上可借此引入「归纳偏置」，不必过度外推到所有深度学习成功叙事。

## 2. Method

### 梳理

生成器 $x=f_\theta(z)$ 通常用 $\theta$ 编码 $p(x)$。本文改解释：固定随机码 $z$，把 $\theta$ 看成图像 $x\in\mathbb{R}^{3\times H\times W}$ 的参数。未训练网络不知物体类别外观，但卷积的局部性与平移不变性、以及多层堆叠的多尺度邻域关系，足以支撑复原类条件问题中的 $p(x|x_0)$。

不显式建模分布，而写能量最小化；用式 (2) 的隐式先验替代式 (1) 的 $R(x)$。

### 提取（公式）

经典：

$$
x^*=\arg\min_x E(x;x_0)+R(x). \tag{1}
$$

DIP：

$$
\theta^*=\arg\min_\theta E(f_\theta(z);x_0),\quad x^*=f_{\theta^*}(z). \tag{2}
$$

- 优化：从随机 $\theta_0$ 梯度下降（Fig.2）。
- 架构影响大；主实验 U-Net 风格 hourglass + skip，$z$ 与 $x$ 同空间尺寸，参数量数百万级。
- 默认**不**优化 $z$。

脚注：可将 (2) 看成 $R(x)=0$ 当图像可由「不太远离随机初始化」的深度 ConvNet 生成，否则 $+\infty$。

### 分析

**论文事实**：先验是手工的（handcrafted），与 TV 同类，但实证更强。  
**批判性分析**：脚注的 $R$ 定义依赖「优化轨迹 / 距初始化不太远」，与完整跑到收敛的可行集不同——去噪必须结合早停理解。CNN 结构本身用户已熟悉，此处关键是**重参数化改变搜索路径**（Fig.3 左），而非新层类型。

## 2.1 A parametrization with high noise impedance

### 梳理

质疑：高容量 $f_\theta$ 几乎能拟合任意图像（含噪声），怎能当先验？回答：虽极限可拟合噪声，但**架构强烈影响梯度下降搜索路径**——抗拒「坏解」，更快走向自然外观。结果要么落到好看的局部最优（Fig.3 左），要么轨迹经过好看解附近（Fig.3 右）。

定量：最简重建 $E=\|x-x_0\|^2$，即

$$
\min_\theta \|f_\theta(z)-x_0\|^2. \tag{4}
$$

Fig.4：自然图、加噪自然图、像素打乱、白噪声四条学习曲线——前两类快，后两类慢。

应用含义：限制迭代次数 ⇒ 投影到「距 $\theta_0$ 不太远的 ConvNet 能生成的图像集合」。

### 提取（步骤流：噪声阻抗实验）

1. 固定架构与随机 $z$。
2. 选目标 $x_0\in\{\text{自然},\text{自然+噪声},\text{打乱},\text{白噪声}\}$。
3. 对 $\theta$ 做梯度下降最小化 (4)。
4. 记录 $E$–迭代曲线；比较收敛速度。

### 分析

**论文事实**：「high impedance to noise and low impedance to signal」。  
**批判性分析**：这是优化动力学证据，不是证明无法最终拟合噪声（文中承认足够长时间仍可拟合）。因此去噪性能与**早停策略**绑定；把 DIP 说成「网络不能表示噪声」是误读。

## 2.2 “Sampling” from the deep image prior

### 梳理

式 (2) 不定义正规图像概率分布，但仍可「松散采样」：随机 $\theta$，看 $f_\theta(z)$（优化起点可视化）。Fig.5：不同深度 hourglass、有无 skip、上采样方式——呈现自相似结构；深度改变特征尺度；skip 混合多尺度，更像自然图像，也是后续复原实验的常用选择。

### 提取

| 架构变体 | 可视化印象（论文描述） |
|---|---|
| Hourglass-1/3/5 | 更深 → 结构尺度变化 |
| Skip-5 | 多尺度结构并存 |
| Skip-5-nearest | 上采样方式影响纹理观感 |

### 分析

**批判性分析**：「samples」加了引号，勿当成 GAN 式从 $p(x)$ i.i.d. 采样。课程用途：直观展示**未训练权重已强加平稳/自相似**。

## 3.1 Denoising and generic reconstruction

### 梳理

目标：从噪声观测 $x_0$ 恢复干净 $x$。可已知噪声模型，或盲去噪。本文主打盲设定，但易嵌入噪声模型。数据项即 (3)(4)。因不需要精确退化模型，可 plug-and-play 处理复杂/未知退化（如 JPEG 伪影，Fig.6–7）。

### 提取（步骤流：DIP 去噪）

1. 选 hourglass（默认带适量 skip / BN 等，见 §4）。
2. 采样并固定 $z$（常加每步扰动 $\sigma_p$）。
3. 随机初始化 $\theta$。
4. 迭代：$\min_\theta \|f_\theta(z)-x_0\|^2$（ADAM）。
5. **早停**（如 1800 step）；可选对末段输出做指数滑动平均；可选多次独立运行再平均。
6. 输出 $x^*=f_{\theta^*}(z)$。

### 提取（关键数值表）

**标准 9 张彩色图，$\sigma=25$：**

| 方法 | PSNR |
|---|---|
| DIP @ 1800 | 29.22 |
| + exp. sliding window | 30.43 |
| + 两次 run 平均 | 31.00 |
| NLM | 30.26 |
| CBM3D | 31.42 |

**真实照片噪声基准 [46]：**

| 方法 | PSNR |
|---|---|
| DIP（Fig.6 同设定） | 41.95 |
| CBM3D | 30.13 |
| 换 UNet | 35.05 |
| 换 ResNet | 31.95 |

JPEG（Fig.6）：~2400 iter 去块效应较好；50K 过拟合。

### 分析

**论文事实**：合成噪声上接近 CBM3D；真实噪声基准上大幅高于 CBM3D；架构差异巨大。  
**批判性分析**：31.00 vs 31.42 仍略低；真实噪声 41.95 的对比依赖同一超参迁移，**未报告**是否对 CBM3D 做同等调参竞赛。UNet/ResNet 数字说明「深度先验」强烈依赖具体拓扑——课程应强调**架构选择 = 先验工程**。

## 3.2 Super-resolution

### 梳理

LR $x_0\in\mathbb{R}^{3\times H\times W}$，因子 $t$，求 HR $x\in\mathbb{R}^{3\times tH\times tW}$。

$$
E(x;x_0)=\|d(x)-x_0\|^2. \tag{5}
$$

$d$ 下采样；$d$ 远非单射 ⇒ 无穷多 HR 对应同一 LR，必须正则。DIP：优化 $\theta$，且 $d$ 与网络均可微（Lanczos）。

### 提取（步骤流）

1. 将 HR 候选参数化为 $x=f_\theta(z)$（$z$ 与 HR 同分辨率）。
2. 用固定可微层实现 $d$（Lanczos2 + resample）。
3. 最小化 $\|d(f_\theta(z))-x_0\|^2$。
4. 默认约 2000 iter（$4\times$），$8\times$ 提到 4000 iter、$\sigma_p=1/20$。
5. 中心裁剪算 PSNR；与 bicubic / TV / Glasner / SelfExSR / LapSRN / SRResNet 等比较。

### 提取（表格：Set14 / Set5 平均 PSNR）

**Set14**

| 方法 | $4\times$ | $8\times$ |
|---|---|---|
| No prior | 24.93 | 22.56 |
| Bicubic | 26.05 | 23.09 |
| TV | 26.42 | 23.48 |
| Glasner / SelfExSR | 26.46 | 23.96 |
| DIP | 27.00 | 24.15 |
| LapSRN | 28.13 | 24.35 |
| SRResNet-MSE | 28.53 | — |

**Set5**

| 方法 | $4\times$ | $8\times$ |
|---|---|---|
| No prior | 26.56 | 23.45 |
| Bicubic | 28.44 | 24.37 |
| TV | 28.85 | 24.87 |
| Glasner / SelfExSR | 28.84 | 25.42 |
| DIP | 29.89 | 25.88 |
| LapSRN | 31.58 | 26.10 |
| SRResNet-MSE | 32.10 | — |

Fig.9：无先验振铃；TV 卡通；DIP 清晰且干净。

### 分析

**论文事实**：公平对比点是 bicubic（同样无外部 HR 数据）；DIP 显著更好，并缩小与监督 MSE 超分差距；相对 SRGAN/EnhanceNet 无法幻觉细节。  
**批判性分析**：表中 $8\times$ Set14 上 DIP 24.15 vs LapSRN 24.35，差距已很小，但 Set5 $4\times$ 仍差 SRResNet 约 2.2 dB。逐图数字见原文 Table 1–2（如 Set14 $4\times$ Lenna：DIP 30.83 vs SRResNet 32.42）。

## 3.3 Inpainting

### 梳理

掩膜 $m\in\{0,1\}^{H\times W}$，

$$
E(x;x_0)=\|(x-x_0)\odot m\|^2. \tag{6}
$$

能量与缺失像素无关 ⇒ 若直接对像素优化，缺失处不会更新；必须先验。DIP 通过对 $\theta$ 优化引入先验。

设定：(i) 去文字；(ii) Bernoulli 丢 50% 像素 vs CSC [44]；(iii) 大洞 vs Global-Local GAN [28]；(iv) 深度/架构消融 Fig.14。

### 提取（步骤流）

1. 定义掩膜 $m$（文字 / 随机 / 大洞）。
2. 选 $z$：大洞常用 meshgrid；其余噪声 $z$。
3. 大洞实验常**去掉 skip**，更深 encoder–decoder。
4. 最小化式 (6) 的 $E(f_\theta(z);x_0)$。
5. 调 LR / 迭代（文字例 6000；大洞例 5000）。

### 提取（Fig.12 vs Papyan et al. [44]，PSNR）

| 图像 | [44] | DIP |
|---|---|---|
| Barbara | 28.14 | 32.22 |
| Boat | 31.44 | 33.06 |
| House | 34.58 | 39.16 |
| Lena | 35.04 | 36.16 |
| Peppers | 31.11 | 33.05 |
| C.man | 27.90 | 29.8 |
| Couple | 31.18 | 32.52 |
| Finger | 31.34 | 32.84 |
| Hill | 32.35 | 32.77 |
| Man | 31.92 | 32.20 |
| Montage | 28.05 | 34.54 |

### 分析

**论文事实**：随机缺失上全面优于所比较的 CSC；大洞利用上下文纹理插值，体现与自相似先验的联系；**更深有益，U-Net skip 对 DIP 大洞有害**。  
**批判性分析**：强语义大洞（人脸）作者主动降期望；Fig.10 显示 LR 可毁掉结果——「无学习」不等于「无超参」。与有监督修复比，缺的是数据集级语义先验。

## 3.4 Natural pre-image

### 梳理

对分类网络前若干层 $\Phi$，自然原像集合

$$
\Phi^{-1}(\Phi(x_0))=\{x:\Phi(x)=\Phi(x_0)\}. \tag{7}
$$

数据项

$$
E(x;x_0)=\|\Phi(x)-\Phi(x_0)\|^2. \tag{8}
$$

直接优化易出非自然「对抗式」伪影。Mahendran & Vedaldi 用 TV；Dosovitskiy & Brox 学习反演网络（更好看但可能偏训练集）。DIP：手工先验 + 更清晰反演。

评测：AlexNet conv1…fc8（Fig.15）；VGG-19（Fig.16）。相对 TV 尤其深层（fc6/fc7）更可解释；相对 [15] 更少 regress-to-mean。

### 提取（步骤流）

1. 固定预训练 $\Phi$（不训练 $\Phi$）。
2. 用 DIP 参数化 $x=f_\theta(z)$。
3. 最小化 $\|\Phi(f_\theta(z))-\Phi(x_0)\|^2$。
4. 可视化不同层深度的原像。

### 分析

**论文事实**：目标是展示「非训练集先验」能做什么，故不与后续加感知损失/判别器的 [14] 比。  
**批判性分析**：定性为主，**未报告**原像任务的定量距离表；「更无偏」是相对学习反演器的方法论主张，难以绝对度量。

## 3.5 Activation maximization

### 梳理

$$
x^*=\arg\max_x \Phi(x)_m. \tag{9}
$$

$m$ 为神经元索引（全连接则取该输出；特征图则取中心像素）。与 TV [38] 比：AlexNet 上 DIP 更自然可解释；VGG-16 上优势不那么清晰（Fig.17–18）。

### 提取

- 超参与 pre-image 相近（§4）：约 3100 iter，LR=0.001，$\sigma_p=0.03$ 等。
- 应用：可视化类别语义；先验仍不来自额外图像集训练。

### 分析

**批判性分析**：激活最大化本就高度依赖正则；DIP vs TV 是正则之争，不是「网络理解」的唯一证据。VGG 上效果减弱说明先验与被可视化模型的交互非平凡。

## 3.6 Image enhancement

### 梳理

利用「先低频后高频/噪声」的拟合顺序：对 $x_0$ 跑重建 (4)，早停得粗近似 $x_c$，

$$
x_f=x_0-x_c,\qquad x_e=x_0+x_f. \tag{10}\text{–}(11)
$$

Fig.19：迭代太少形状不准（光晕）；太多数高频噪声出现——需选停止点。

### 提取（步骤流）

1. 拟合 $\|f_\theta(z)-x_0\|^2$，记录不同 iter 的 $x_c$。
2. 抽细节并放大加回。
3. 人工或启发式选择停止点（噪声水平已知时可借鉴 inverse scale space 停止准则，§5 提及）。

### 分析

**论文事实**：增强是重建轨迹的副产品。  
**批判性分析**：停止点选择定性展示为主；**未报告**增强任务的标准定量基准分数。

## 3.7 Flash-no flash reconstruction

### 梳理

目标：光照像 no-flash，噪声水平借 flash 引导降低。多图扩展通常需协调优化多个 $z$；本例发现：把 **flash 图当作输入 $z$**，对 no-flash 做去噪式拟合 (4) 即可——非线性版 guided filter。Fig.20 定性优于 joint bilateral，闪光图案泄漏更少。

### 提取（步骤流）

1. 不以随机张量为 $z$，而以 flash 图像为网络输入。
2. 目标：$f_\theta(\mathrm{flash})\approx \mathrm{no\text{-}flash}$（L2）。
3. 优化 $\theta$；输出作为复原结果。

### 分析

**论文事实**：展示单图框架可扩展到引导复原。  
**批判性分析**：仅定性一例；视频等多图设定**未系统评测**。将引导图塞进 $z$ 通道是巧妙工程，理论地位弱于单图主定理。

## 4. Technical details

### 梳理

- 主用全卷积；$z$ 与输出同空间分辨率。
- Hourglass ± skip（Fig.21）；LeakyReLU；stride 下采样；上采样双线性/nearest；reflection padding（反演/激活最大化例外）。
- $z$：均匀噪声或 meshgrid（Fig.22）。
- 输入噪声正则 $\sigma_p$：阻碍优化但足够长时间仍可把目标拟合到 0。
- 损失突增时回退上一 iter 参数。
- 优化器 ADAM；框架 PyTorch；每图数分钟。
- 各任务超参列表：通道数 $n_u,n_d,n_s$，核大小，iter，LR，$\sigma_p$ 等（超分默认 $n=128\times5$，iter=2000，LR=0.01，$\sigma_p=1/30$ …）。

### 提取（默认超分架构摘要）

| 项 | 值 |
|---|---|
| $z$ | $\mathbb{R}^{32\times W\times H}\sim U(0,1/10)$ |
| $n_u=n_d$ | $[128]\times 5$ |
| $k_u=k_d$ | $3$ |
| skip $n_s,k_s$ | $4$, $1$ |
| $\sigma_p$ | $1/30$（$8\times$ 用 $1/20$） |
| iter | 2000（$8\times$: 4000） |
| LR | 0.01 |
| upsample | bilinear |

去噪 Fig.7：同超分但 1800 iter；滑动平均 $\gamma=0.99$。

### 分析

**论文事实**：宽超参范围「可接受」，但最佳需按任务甚至按图微调。  
**批判性分析**：可复现性依赖冗长超参表；「数分钟」未给硬件型号与精确墙钟/**未报告显存**。课程实验若复现，应固定随机种子并记录早停规则。

### 梳理

关联脉络：

1. **滤波响应统计**（Field、小波、随机滤波器响应 similarly structured）。
2. **无 hold-out 训练、利用自相似**：NLM、BM3D、Glasner 单图超分；复杂未知退化时尤其有用。
3. **ZSSR [1]**：从单图补丁造合成数据训前馈超分——与 DIP 互补（跨尺度自相似 vs 同尺度多尺度结构）。
4. **Fields of Experts、字典 / 卷积稀疏编码**：在退化图上拟合；深度 ConvNet 先验在修复比较中优于单层 CSC [44]。
5. **DeconvNets、结合自相似的学习去噪 [37]**。
6. **Inverse scale space**：由粗到细、早停去噪；经典方法常被 TV 驱动，难处理纹理；DIP 可借用其停止准则（噪声水平已知时）。
7. 本文相对 CVPR 会议版 [59]：更多直觉/可视化/技术细节/实验；补充激活最大化与高频增强；并列举后续 DIP 应用（压缩感知、事件相机、对抗防御、ptychography 等）。

### 分析

**论文事实**：明确把自己放在「学习式深度复原」与「自相似无学习复原」之间。  
**批判性分析**：相关工作对「为何卷积 ⇒ 自相似」偏思辨；严格理论联系更多留给后续文献。与 ZSSR 的「互补」表述有助于 Lec1 组织阅读顺序。

## 6. Discussion

### 梳理

拆分贡献：架构施加的先验 vs 外部图像经学习转入的信息。随机初始化 ConvNet 拟合退化图可作复原「瑞士军刀」。

**自承局限**：

1. 太慢，多数实用场景不如任务专用前馈网；
2. 难以匹配或超过问题专用方法的精度。

尽管实用有限，跨任务好结果说明：**隐式架构先验是深度复原成功的重要组成部分**。

思辨：卷积在整幅视野共享滤波 ⇒ 输出平稳性 / 自相似（Fig.5）；hourglass+skip ⇒ 多尺度自相似，适合自然图像。

叙事冲击：部分反对「深度学习复原成功只因能学习、而非手工先验」；恰当手工的网络架构 ≈ 更好的手工先验；学习建立在此基础之上——也支持继续做架构研究。

### 分析

**论文事实**：两句主局限（慢、精度天花板）写得很直白。  
**批判性分析 / 课程落点**：Lec1 应把 DIP 读成**存在性证明与概念工具**，不是 SOTA 刷榜器。后续 VAE/GAN/扩散课可反复回指：生成器架构在随机初始化时已非「空白石板」。

## 全文方法步骤流（汇总）

```text
输入：退化图 x0，任务类型 → 选定 E(·;x0)
选择：架构 f（深度/是否 skip/上采样）、z 类型、σp、LR、最大迭代、早停规则
初始化：θ ~ 随机；z 固定（flash-no-flash 例外：z←flash）
循环 t = 1..T:
  x ← f_θ(z)           # 可对 z 加噪
  L ← E(x; x0)
  θ ← ADAM 更新
  若损失突增：回退 θ
  若去噪类：监控并考虑早停 / 滑动平均
输出：x* = f_θ*(z)（或滑动平均版本）
```
