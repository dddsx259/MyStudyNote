## 与课题关联（MIT 6.S978 Lec1）

Lec1 的核心命题之一是：**深度生成模型的成功，有多少来自「学到的参数」，又有多少来自「结构本身的归纳偏置」？** Deep Image Prior（DIP）给出一个极端对照实验：

- **论文事实**：不在大数据上训练生成器；把**随机初始化**的 ConvNet 当作图像的**参数化**，只拟合**单张**退化图，就能在去噪、超分、修复等逆问题中接近甚至局部超过经典无学习先验，并缩小与监督学习方法的差距。
- **课程翻译**：「结构本身即先验」——hourglass / 卷积 / 多尺度自相似性，在任何梯度下降之前就已经偏向自然图像统计。
- **与同讲其他论文的衔接**：Zoran–Weiss 等强调「自然图像局部统计可用简单概率模型刻画」；DIP 则说「深度生成器架构本身就编码了自相似性类先验」，把手工先验与学习先验之间的鸿沟桥接起来。

更细一点看 Lec1 叙事线：前面的自然图像统计工作回答「先验长什么样」；DIP 回答「现代深度生成器骨架是否已经偷偷内置了这类先验」。若答案为是，则后续讲 VAE / GAN / 扩散时，就不能把随机初始化的生成器当成信息论意义上的空白石板——**优化从第一步起就在非均匀的假设类里走**。这也解释了为何同样是「拟合一张图」，直接优化像素（无先验）会出现振铃或噪声，而优化网络权重却更像「有正则的复原」。

## 背景与问题

### 研究动机

当时去噪、超分、表示反演等任务上，深度 ConvNet 表现强劲，常见叙事是：网络从海量图像**学会了**真实图像先验。但 Zhang et al.（ICLR 2017）等结果表明：同一网络也能过拟合随机标签——说明**结构与数据是否「共振」**同样关键。在图像生成 / 复原语境下，结构先验的贡献仍不清楚。

另一条历史线索是无学习复原：TV、非局部均值、BM3D、基于块自相似的单图超分等。它们不靠外部训练集，而靠「自然图像应分段平滑 / 应有重复块」等假设。深度学习兴起后，两条路线常被对立叙述成「手工特征 vs 端到端学习」。DIP 的尖锐之处在于：它用深度学习的**架构语言**写出一个本质上仍是**手工**的先验，从而证明对立并不彻底。

### 本文要回答的问题

1. 生成器 ConvNet 的**架构**本身，是否已捕获大量低层自然图像统计（无需学习 $\theta$）？
2. 若把未训练网络当作**手工先验**，能否求解标准逆问题（去噪、超分、修复）？
3. 同一先验能否用于诊断分类网络（natural pre-image、activation maximization），以及 flash–no-flash 等扩展设置？

### 与三类先验的对照（读论文时的坐标）

| 类型 | 代表 | 信息从哪来 | DIP 相对位置 |
|---|---|---|---|
| 经典手工先验 | TV、小波稀疏、自相似 / BM3D | 人写的正则或块匹配规则 | 同属「无外部训练」；DIP 通常更锐利、少卡通化 |
| 学习先验 / 监督复原 | SRResNet、LapSRN、学习反演网 | 大数据上的 $\theta$ | DIP 无此信息源，故难幻觉语义细节，但诊断时更少训练集偏差 |
| 单图内部学习 | ZSSR 等 | 从同一张图造合成对再训前馈网 | 互补：ZSSR 偏跨尺度自相似；DIP 偏同尺度、由架构强加的多尺度平稳性 |

## 方法与公式

### 一句话直觉

**把「待恢复图像」写成 $x=f_\theta(z)$，其中 $f$ 是固定结构的生成器、$z$ 固定随机张量；只优化 $\theta$ 去拟合退化观测。**  
网络容量虽大，但梯度下降轨迹对「自然结构」阻抗低、对噪声阻抗高——因而可作先验；噪声类任务往往还需**早停**，以免最终过拟合到退化图。

CNN / encoder–decoder / U-Net：当作熟悉的 hourglass 即可，下文不展开层型细节。

### 经典能量 vs DIP 重参数化

传统形式（数据项 + 显式正则）：

$$
x^*=\arg\min_x\, E(x;x_0)+R(x). \tag{1}
$$

DIP **去掉显式** $R(x)$，改用网络参数化：

$$
\theta^*=\arg\min_\theta\, E\bigl(f_\theta(z);x_0\bigr),\qquad x^*=f_{\theta^*}(z). \tag{2}
$$

- $z\in\mathbb{R}^{C'\times H'\times W'}$：通常固定随机初始化；多数实验不优化 $z$。
- $\theta$：卷积核与偏置；从随机初始化出发用梯度下降（实验用 ADAM）。
- **脚注直觉**：$R(x)=0$ 当 $x$ 可由「不太偏离随机初始化」的 ConvNet 生成，否则 $+\infty$——先验是**轨迹约束 / 阻抗**，不是显式概率密度。

### 两类问题几何（Fig. 3）

| 类型 | 例子 | 现象 |
|---|---|---|
| 解流形上 $E=0$ | 超分、部分修复 | 无数解满足数据项；先验决定落点；DIP 通过重参数化弯曲优化轨迹 |
| $E(x_{\mathrm{gt}})>0$ | 去噪 | 充分优化会逼近 $E\approx 0$ 从而拟合噪声；轨迹常先靠近干净像，需**早停** |

### 噪声阻抗实验（§2.1，Fig. 4）

重建目标 $E(x;x_0)=\|x-x_0\|^2$，拟合四类 $x_0$：自然图、自然图+噪声、像素打乱、白噪声。  
**论文事实**：自然像 / 加噪自然像收敛明显更快；打乱与白噪声「不情愿」被拟合。即：**对噪声高阻抗、对信号低阻抗**。

这对去噪的操作含义是：优化路径往往先重建「像自然图像的成分」，噪声成分后到。因此把迭代截断在「已经恢复结构、尚未吞下噪声」的窗口，等价于把解限制在距随机初始化不远的参数区域（Fig.3 右）。超分则更接近 Fig.3 左：数据项可被许多 HR 完美满足，DIP 的作用是让优化落在更干净、更锐利的那一类解上，而不是靠「拒绝拟合」——此时早停仍可能有用，但叙事重心是重参数化而非噪声阻抗。

### 「从先验采样」（§2.2，Fig. 5）

随机 $\theta$ 下看 $f_\theta(z)$：呈现空间结构与自相似；深度控制尺度；**skip 连接**混合多尺度结构——作者认为这更贴近自然图像，也是多数实验选用 hourglass+skip 的原因（注：大洞修复等例外见下）。Discussion 进一步猜测：卷积滤波器在整幅视野共享，天然倾向输出的平稳性与重复结构；这与经典自相似先验「同图多处纹理重复」在现象上同向，但实现机制是共享卷积核而非显式块匹配。

### 各任务数据项（论文事实）

| 任务 | 数据项 $E$ | 读法 |
|---|---|---|
| 去噪 / JPEG / 增强粗像 | $\|x-x_0\|^2$ | 直接逼近观测；靠早停抗噪 |
| 超分（因子 $t$） | $\|d(x)-x_0\|^2$，$d$ 为可微下采样（Lanczos2 + 重采样） | 无数 HR 共享同一 LR；先验选解 |
| 修复（掩膜 $m$） | $\|(x-x_0)\odot m\|^2$ | 缺失处无直接梯度；先验「填空」 |
| Natural pre-image | $\|\Phi(x)-\Phi(x_0)\|^2$ | 在自然像集合里找同表示点 |
| Activation max | 最大化 $\Phi(x)_m$（等价最小化负激活） | 合成高激活图像，需强正则防噪声 |

### 优化与实现要点（§4）

- 架构：全卷积 hourglass（可选 skip）；LeakyReLU；stride 下采样；双线性或最近邻上采样（转置卷积更差）；多数任务 reflection padding。
- 输入 $z$：均匀噪声 $U(0,0.1)$，或 meshgrid（大洞修复额外平滑先验）。
- 可选：每步给 $z$ 加 $\mathcal{N}(0,\sigma_p^2)$ 扰动；损失突增时回退参数。作者观察到：加噪会拖慢优化，但足够多步后网络仍常能把目标拟合到接近零——再次说明「先验」主要来自有限步动力学，而非绝对不可表示噪声。
- 墙钟：每张图需反复前向+反向，「数分钟」量级；**显存未报告**；硬件型号**未报告**。

### 方法步骤流（便于复现笔记）

1. 根据任务写好可微数据项 $E$（上表）。
2. 选定 hourglass 深度、是否 skip、上采样方式与 $z$ 类型。
3. 随机初始化 $\theta$，固定 $z$（flash–no-flash 时用闪光图替换 $z$）。
4. ADAM 迭代更新 $\theta$；监控损失突变并回退。
5. 去噪 / JPEG / 增强：选早停点，必要时做指数滑动平均或多次独立运行平均。
6. 输出 $x^*=f_{\theta^*}(z)$；超分再中心裁剪计 PSNR。

## 实验设置与关键数值

### 去噪（§3.1）

**合成高斯噪声 $\sigma=25$（9 张彩色图）**：

| 方法 | PSNR |
|---|---|
| DIP，1800 step | 29.22 |
| + 末段指数滑动平均 | 30.43 |
| + 两次优化再平均 | **31.00** |
| NLM（无预训练） | 30.26 |
| CBM3D（无预训练） | **31.42** |

**真实噪声基准 [46]**（与 Fig.6 同架构与超参）：DIP **41.95** vs CBM3D **30.13**。  
同设定换架构：hourglass 类主方法强；UNet **35.05**、ResNet **31.95**——作者推测 UNet skip 过宽使先验过弱、拟合过快；ResNet 无 skip 使先验过强、拟合过慢。

JPEG 伪影（Fig.6）：约 2400 iter 时块效应/光晕大部消除；50K iter 过拟合输入。

### 超分（§3.2，Table 1–2，中心裁剪 PSNR）

**Set14 平均**：

| 方法 | $4\times$ | $8\times$ |
|---|---|---|
| No prior | 24.93 | 22.56 |
| Bicubic | 26.05 | 23.09 |
| TV prior | 26.42 | 23.48 |
| Glasner / SelfExSR | 26.46 | 23.96 |
| **Ours (DIP)** | **27.00** | **24.15** |
| LapSRN（有监督） | 28.13 | 24.35 |
| SRResNet-MSE（有监督） | 28.53 | — |

**Set5 平均**：

| 方法 | $4\times$ | $8\times$ |
|---|---|---|
| No prior | 26.56 | 23.45 |
| Bicubic | 28.44 | 24.37 |
| TV prior | 28.85 | 24.87 |
| Glasner / SelfExSR | 28.84 | 25.42 |
| **Ours (DIP)** | **29.89** | **25.88** |
| LapSRN | 31.58 | 26.10 |
| SRResNet-MSE | 32.10 | — |

**论文事实**：DIP 明显优于 bicubic / TV / 单图自相似类无学习方法，仍低于 MSE 监督超分；相对 GAN 超分无法「幻觉」训练集高频细节。Fig.9：像素直接优化有振铃；TV 去振铃但卡通化；DIP 更干净且锐利。

### 修复（§3.3）

- 文字修复：相对 Shepard networks [47]，DIP 更自然、少光晕（定性）。
- 50% 随机丢像素：相对卷积稀疏编码 [44]，Fig.12 逐图 PSNR 全面更高，例如 Barbara **32.22 vs 28.14**，House **39.16 vs 34.58**，Montage **34.54 vs 28.05**。
- 大洞：可与 Global-Local GAN [28] 定性接近；对强语义大洞（如人脸）**不期望**可靠；学习率敏感（Fig.10）。
- 架构消融（Fig.14）：更深更好；**对 DIP，U-Net 式 skip 对大洞修复有害**（与识别任务相反）。

### 表示诊断与其他应用

- **Natural pre-image**（AlexNet / VGG-19）：相对 TV，清晰度大幅提升；相对学习反演网络 [15]，更少「回归均值」式偏差，且先验未从外部集学习。
- **Activation maximization**：AlexNet 上 DIP 比 TV 更可解释；VGG-16 上差异不那么清晰。
- **细节增强**：早停得粗像 $x_c$，细节 $x_f=x_0-x_c$，增强 $x_e=x_0+x_f$。
- **Flash–no-flash**：用 flash 图代替随机 $z$，目标拟合 no-flash；定性优于 joint bilateral，更少闪光「泄漏」。

## 消融与设计选择

| 因素 | 论文观察 |
|---|---|
| 深度 | 更深 hourglass 常更好（修复 Fig.14） |
| Skip | 多任务「采样」与自然多尺度有利；大洞修复中有害 |
| 上采样 | 双线性 / nearest；转置卷积更差 |
| 早停 / 滑动平均 | 去噪类关键；超分更偏「解流形」型 |
| $z$ 类型 | meshgrid 利于大洞；其余多用噪声 $z$ |
| 架构族 | 同任务上 hourglass vs UNet vs ResNet 差距可极大（真实噪声） |

## 优势 / 局限

### 优势（论文事实 + 课程价值）

- 无外部训练数据；degradations 复杂/未知时「即插即用」（JPEG、未知真实噪声、闪光引导等）。
- 桥接：**学习式 ConvNet 复原** ↔ **自相似 / TV 等无学习先验**；用一种语言同时对话两派文献。
- 诊断分类网络时，先验本身不引入训练集偏差（相对学习式反演器）；深层原像仍常可解释。
- 概念清晰：一个公式 (2) 覆盖多任务，只换 $E$，适合作为 Lec1「先验到底是什么」的教学探针。

### 局限（论文自述 + 批判性）

- **慢**：每图迭代优化数分钟；实际部署不如任务专用前馈网。
- **精度天花板**：多数任务仍低于专用监督学习；无法像 GAN 超分幻觉训练集高频细节。
- **超参敏感**：迭代数、LR、是否 skip、早停点影响大；「万能」但需调；大洞修复对 LR 尤其敏感。
- **批判性分析**：Fig.4 证明的是优化动力学偏置，不是严格贝叶斯先验；「采样」仅为随机 $\theta$ 可视化。真实噪声 41.95 vs CBM3D 30.13 的设定依赖作者选定架构/超参，外推需谨慎。大洞上「去掉 skip」与超分默认「带 skip」说明**先验强度依赖任务**，不能把「U-Net 万能」直接搬过来。合成噪声上即便两次平均也仍略低于 CBM3D（31.00 vs 31.42），叙事上应写成「进入无学习强基线区间」，而非「全面取代协同滤波」。

## 可迁移启示（面向 Lec1 / 后续生成模型）

1. 解释深度生成模型时，应拆开 **架构归纳偏置** 与 **参数学习**；DIP 是前者的极限实验。
2. 「过拟合噪声 + 早停」与 inverse scale space / 逐步恢复频率的经典思想同构；扩散等后续模型也常有「先粗后细」轨迹——阅读时可把 DIP 的学习曲线当作低配版「时间方向」。
3. 设计新架构 ≈ 设计更好的手工先验；验证了「架构研究」本身的价值，而不是把一切进步都归因于更大数据。
4. 单图内部统计（自相似）仍可被深度结构隐式利用——与 ZSSR 等多尺度单图学习互补；做文献综述时不要把「无外部数据」的方法都当成同一类。
5. 做网络可视化 / 反演时，正则选择会改变结论：TV、DIP、学习反演器会讲出不同故事；报告诊断结果时应写明先验来源。

## 贡献与一句话总结

**贡献**：首次系统论证——在**不学习网络参数于图像集**的前提下，深度卷积生成器结构即可作为强图像先验，并在多种逆问题与网络诊断任务上实证；扩展版补充激活最大化、细节增强与更完整超参。

**一句话**：Deep Image Prior 用「随机初始化生成器拟合单张退化图」证明：**结构即先验**；对噪声需早停，对超分/修复则靠重参数化选择合理解。

---

## 五段式精炼要点

1. **问题**：深度复原的成功究竟靠学到的先验，还是靠网络结构？
2. **方法**：固定 $z$，优化 $\theta$ 使 $f_\theta(z)$ 满足任务数据项；无显式 $R(x)$。
3. **机制**：自然信号易拟合、噪声难拟合；必要时早停；架构（深度/skip）决定先验强弱。
4. **证据**：去噪逼近 CBM3D（31.00 vs 31.42）；超分超 bicubic/TV 并接近监督 MSE 方法；修复超 CSC；反演优于 TV。
5. **课程含义**：生成模型课应把「未训练结构的归纳偏置」当作一等公民，而非默认一切来自大数据。
