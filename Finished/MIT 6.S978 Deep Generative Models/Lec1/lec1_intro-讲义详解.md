## 0. 这一讲要建立的世界观（先看结论）

He 老师这一讲几乎不推具体算法公式，而是先钉死三件事：

1. **GenAI 不是突然出现的**：Photoshop 内容感知填充、纹理合成等早已是「生成」。
2. **生成 ≠ 必须是神经网络**：核心是「如何表示并预测分布」；深度网络只是强表示工具。
3. **大量现实问题都能写成 $p(x\mid y)$**：关键是你怎么定义「条件 $y$」和「样本 $x$」。

读完后你应能回答：判别式与生成式差在哪、贝叶斯怎么把生成模型当分类器用、为什么「无条件生成」其实仍是条件生成、深度生成模型相对经典方法多了什么。

## 1. GenAI 时代的例子（幻灯 2–7）

### 幻灯在说什么

一串应用：对话、文生图（Stable Diffusion）、文生视频（Sora）、代码助手、蛋白质设计（RFdiffusion）、雷达降水临近预报。

### 展开

这些例子表面形态不同，但共享同一数学外壳：**给定某些条件，输出高维、多解、且「看起来合理」的样本**。

- 对话：条件 = 上文；样本 = 下一句/整段回复。
- 文生图：条件 = 文本；样本 = 像素阵列。
- 蛋白质：条件 = 功能/对称性等约束；样本 = 3D 结构。

「合理」不是说只有一个正确答案，而是：**在数据与先验暗示的分布下，概率质量高的区域**。这也是后面为什么必须谈概率建模。

## 2. GenAI 之前：经典「生成」（幻灯 8–9）

### 幻灯在说什么

- **PatchMatch (2009)**：Photoshop Content-aware Fill 的核心算法之一。
- **Efros–Leung (1999)**：非参数纹理合成；He 明确说 *In today’s word: this is an Autoregressive model*。

### 展开：为什么 Efros–Leung ≈ 自回归？

自回归（Autoregressive, AR）的核心不是「用了 Transformer」，而是**因式分解**：

$$
p(x_1,x_2,\ldots,x_N)=\prod_{i=1}^{N} p(x_i\mid x_{<i})
$$

Efros–Leung 从种子向外一像素一像素「长」纹理：下一个像素的分布，由已合成邻域在示例图中找相似邻域来估计。依赖顺序是**人设计的**（扫描/外扩顺序），条件分布用**非参数查表**近似——这正是 AR 的骨架；今天的 PixelCNN / GPT 只是把 $p(x_i\mid x_{<i})$ 换成深度网络。

PatchMatch 则是高效求**最近邻场（NNF）**：随机初始化 + 传播好匹配 + 随机搜索。它支撑补洞、重定向等「用图像自身补图像」的编辑，和后面 Deep Image Prior、自相似先验一脉相承。

> 同讲阅读：`Texture Synthesis…`、`PatchMatch…` 文件夹里的中文总结/详解。

## 3. 这些场景的共同点（幻灯 10–11）

He 列出四条：

| 共同点 | 白话 |
|---|---|
| 一对多（甚至无限多）输出 | 同一 prompt 可生成无数张图 |
| 有的输出比另一些「更说得通」 | 需要排序/打分 → 分布 |
| 训练数据未必含「精确解」 | 尤其开放生成、设计类任务 |
| 输出往往比输入更复杂、更高维 | 文本 → 图像/视频/结构 |

**判别式任务**常假设「一个输入对应一个（或少数）目标」；生成任务默认**一对多**。因此建模对象从「点估计 $f(x)$」变成「条件分布 $p(\cdot\mid\cdot)$」。

## 4. 判别式 vs 生成式（幻灯 12–15）——必懂

### 4.1 方向相反

| | 判别式 | 生成式（本讲口径） |
|---|---|---|
| 典型映射 | 样本 $x$ → 标签 $y$ | 标签/条件 $y$ → 样本 $x$ |
| 学什么 | $p(y\mid x)$ 或决策边界 | $p(x\mid y)$（或无条件 $p(x)$） |
| 输出个数 | 常希望唯一正确 | 允许多个合理样本 |

你在 `notes.md` 里写的 $P(y\mid x)$ / $P(x\mid y)$ 方向是对的。

### 4.2 生成 → 判别：贝叶斯公式（展开）

**一句话直觉**：若你会「在类别 $y$ 下生成 $x$」且知道类别先验，就能用贝叶斯反推「看到 $x$ 更像哪一类」。

$$
p(y\mid x)=\frac{p(x\mid y)\,p(y)}{p(x)}
$$

- $p(x\mid y)$：生成模型（似然）
- $p(y)$：先验（如各类频率）
- $p(x)=\sum_{y'}p(x\mid y')p(y')$：证据；对固定的 $x$ 只是归一化常数，**做 $\arg\max_y$ 分类时常可忽略**

经典「生成式分类器」例子：朴素贝叶斯、线性判别分析（LDA）——先建类条件密度，再贝叶斯决策。

### 4.3 判别 → 生成？更别扭

若只有 $p(y\mid x)$，想得到 $p(x\mid y)$：

$$
p(x\mid y)=\frac{p(y\mid x)\,p(x)}{p(y)}
$$

你还缺 **$p(x)$（数据边缘分布）**。而 $p(x)$ 在图像等高维空间上极难：这正是「深度生成模型」要啃的骨头。  
所以幻灯结论：**挑战在于表示并预测分布**——尤其是对 $x$ 的分布。

### 4.4 和「隐变量故事」的关系（对接你笔记最后一句）

幻灯 15–16 的叙事：

- 假设存在隐因子 $z$（姿态、光照、尺度…），$z$ 的分布简单（如高斯）
- 观测 $x$ 由「世界模型」$x = g(z)$（或带噪声）渲染出来 → $x$ 的分布很复杂

这不是说世界里真有可观测的 $z$，而是**建模假设**：用简单 $z$ + 复杂映射 $g$，解释复杂 $x$。VAE、很多扩散/流模型都吃这套语言。  
你笔记里「假设数据服从隐变量 $z$」正对应这里——后面 Lec2 VAE 会把它写成可优化目标。

## 5. 「概率是建模的一部分」（幻灯 15–21）

### 5.1 两种态度

1. **本体论**：数据生成过程背后「真有」分布。
2. **工具论（幻灯更强调）**：我们只看到有限样本；模型用分布去**外推**；过拟合/欠拟合和判别式一样存在。

### 5.2 密度估计的过拟合卡通（幻灯 17–21）

想象一维数据点，估计密度 $p(x)$：

- **欠拟合**：一条太平滑的曲线，抹掉多峰结构。
- **「刚好」**：抓住主要模态。
- **过拟合**：在每个训练点上堆很尖的峰。
- **极端**：用 $\delta$ 函数钉在每个训练样本上 → 「采样」等于从训练集里抽图，**零泛化**。

这对生成模型极重要：能完美记住训练集 ≠ 好生成模型；要的是在未见过但「像真数据」的区域也有合理概率质量。

## 6. 带概率建模的生成流水线（幻灯 22–27）

幻灯画了一条链：

```text
有限数据
   →（建模假设）真实数据分布 p_data   ← 这一步本身就是假设
   → 估计分布 p_θ
   → 两件可选能力：
        (a) 采样：画出新「数据」
        (b) 估计密度：问 p_θ(x)=?
```

**Notes（幻灯原意，建议背住）：**

- 统计模型常是**人设计**的（因式分解、扩散前向过程、GMM 分量等），不全是网络「学」出来的。
- 概率建模 ≠ 只有神经网络能干；GMM、MRF、非参数方法都是。
- 概率路线很流行，但**不是唯一**路线（例如某些纯能量模型、或纯「匹配/检索」系统）。
- George Box：*All models are wrong, but some are useful.*

> 同讲连接：EPLL 的 GMM patch 先验、Dead Leaves 对 GMM 的物理解释，都是「人设计统计结构 + 从数据估参数」。

## 7. 什么是 Deep Generative Models？（幻灯 28–35）

### 7.1 深度学习和「表示」的两层含义

你熟悉的深度学习：**学习数据实例的表示**

$$
x \mapsto f_\theta(x) \quad\text{（特征）},\quad \text{再配合任务损失}
$$

深度生成模型额外强调：**学习概率分布的表示**

$$
\text{简单分布 } p(z)\ \xrightarrow{\;g_\theta\;}\ \text{复杂分布 } p_\theta(x)
$$

常两者一起做：既要好特征，又要能采样/估密度。

**直觉**：判别网络问「这个 $x$ 是什么」；生成网络问「从简单噪声出发，如何变出像数据的 $x$」。

### 7.2 不是所有结构都靠学习——两个案例

#### 自回归（幻灯 31–32）

- **人设计**：依赖图 / 生成顺序（像素扫描、token 从左到右）。
- **网络学**：每个条件分布 $p(x_i\mid x_{<i})$ 的参数（MLP / CNN / Transformer）。

#### 扩散（幻灯 33–34）

- **人设计**：加噪马尔可夫链、时间步离散化、往往固定的高斯核。
- **网络学**：每一步去噪映射（常 U-Net；你 d2l 里的编解码/跳连直觉够用）。

**课程级结论**：Deep Gen 模型 = **人工分解复杂分布** + **深度网拟合剩余难建模部分**。

### 7.3 五个组件清单（幻灯 35）

| 组件 | 含义 |
|---|---|
| Formulation | 把问题写成概率建模；把复杂分布拆成可处理的一块块 |
| Representation | 深度网表示数据与分布 |
| Objective | 如何度量「预测分布好不好」（似然、ELBO、对抗、分数匹配…） |
| Optimization | 优化网络和/或分解结构 |
| Inference | **采样器**（几乎总要）；**密度估计**（可选，很多大模型并不给出精确 $p(x)$） |

作业/读论文时可用这五栏做检查表。

## 8. 把现实问题写成 $p(x\mid y)$（幻灯 36–49）——本讲实操核心

### 8.1 $x$ 与 $y$ 的语义

| | 典型角色 | 性质 |
|---|---|---|
| $y$ | 条件 / 约束 / 标签 / 属性 / prompt | 更抽象、信息更少 |
| $x$ | 数据 / 样本 / 观测 / 测量 | 更具体、信息更多 |

生成模型关心：**在 $y$ 固定时，$x$ 可以是什么、哪些更可能**。

### 8.2 案例速查表（对照幻灯）

| 任务 | $y$（条件） | $x$（生成物） |
|---|---|---|
| 聊天机器人 | prompt / 对话历史 | 回复文本 |
| 文生图/视频 | 文本 | 图像/视频 |
| 文生 3D | 文本 | 3D 结构 |
| 蛋白质设计 | 对称性等约束 | 蛋白结构 |
| 类别条件生成 | 类别（如 “red fox”） | 图像 |
| 「无条件」生成 | *隐含*「属于某数据集分布」 | 该数据集风格的图像 |
| 分类（生成视角） | 图像 | 类别上的概率（注意：这里 $x,y$ 命名与上面「样本」对调，见下） |
| 开放词表识别 | 图像 | 多个合理描述/标签 |
| 图像描述 | 图像 | 句子 |
| 视觉聊天 | 图像 + 文本 | 回复 |
| 机器人策略 | 视觉等感知 | 动作分布（策略） |

### 8.3 「无条件生成」其实是条件生成（幻灯 43）

幻灯点破：

- 说「无条件」CIFAR 生成，其实是 $p(x\mid y=\text{“像 CIFAR10 的图”})$
- 真正的 $p(x)$ 若指「一切可能图像」则几乎无用、也无法从 CIFAR 单独学到

**建模时永远要想清：你的训练集定义了什么条件。**

### 8.4 分类为何也能叫「生成视角」（幻灯 44）

这里符号容易晕。幻灯把：

- 条件 = 图像  
- 输出 = 类别概率  

写成 $p(x\mid y)$ 是在统一口头禅「条件 → 多样/不确定输出」。若你沿用机器学习教材符号，分类更常写作 $p(y\mid x)$（$x$=图像，$y$=类）。  
**不必纠结字母**：抓住「输入条件 vs 输出随机变量」即可。开放词表识别、图像描述则是：同一图像对应**多个合理文本输出**，更像标准条件生成。

### 8.5 机器人 Diffusion Policy（幻灯 48）

条件 = 观测；输出 = 动作序列上的分布。行为本身多解（同一场景多种合法动作），故用生成模型（如扩散）拟合策略分布，而不是只回归一个平均动作——平均动作可能落在「两合法动作中间」的非法区。

## 10. 与本讲 Reading List 的挂钩（帮你串起来）

| 阅读 | 落在 Lec1 哪块地图上 |
|---|---|
| Efros–Leung | 前 GenAI 的 AR 纹理；非参数 $p(\text{pixel}\mid\text{邻域})$ |
| PatchMatch | 高效对应场 → 结构编辑 / 补洞 |
| Freeman Example-SR | 示例驱动：从成对 patch 学「条件」高频 |
| EPLL (Zoran & Weiss 2011) | 用 patch 先验整图复原；似然与复原的关系 |
| GMM & Dead Leaves (2012) | 简单统计模型为何够强；遮挡物理解释 |
| Deep Image Prior | **网络结构本身**已是先验；未必先大数据训练 |

叙事线可以记成：

```text
经典 patch / 自相似 / 非参数
    → 可学习的概率先验（GMM + EPLL）
    → 深度网：学分布的表示
    → DIP：有时结构先验已够用
    → 现代 AR / 扩散：人设分解 + 网学映射
```

## 11. 建议你立刻在 `notes.md` 里补的三句话（可选）

1. 生成式核心挑战是表示 $p(x)$ 或 $p(x\mid y)$，不是背网络名字。  
2. 贝叶斯：会生成 $p(x\mid y)$ + 先验 ⇒ 可判别；反过来缺 $p(x)$ 很难。  
3. Deep = 表示学习；Deep Generative = 还要表示「简单分布 → 复杂分布」的映射，且分解结构常是人设计的。

## 附录：本讲公式速查

**贝叶斯（生成 → 判别）**

$$
p(y\mid x)=\frac{p(x\mid y)p(y)}{p(x)}
$$

**自回归分解**

$$
p(x)=\prod_i p(x_i\mid x_{<i})
$$

**隐变量生成故事（概念）**

$$
z\sim p(z),\quad x = g_\theta(z)\ \text{（或 }x\sim p_\theta(x\mid z)\text{）}
$$

**条件生成统一写法**

$$
x\sim p_\theta(x\mid y)
$$
