Discriminative Models vs Generative Models
+ Discriminative Models: 
    + Learn a function to map input to output
    + i.e. P(y|x)
    + e.g.:
      + a dog's image -> model -> "dog"
+ Generative Models:
    + Learn how to generate data base on the data distribution
    + i.e. $P(x|y)$
    + e.g.:
      + "dog" -> model -> a dog's image
    + The generative models can be discriminative by Bayes' rule:
    + $$P(y|x)=P(x|y)\frac{P(y)\rightarrow\text{prior}}{P(x)\rightarrow\text{evidence}}$$
    + Vice versa, the discriminative models can also be generative by the similar way.
  
We assume that the data follow some **latent variables** $z$, which has simple distribution, and the data is generated by the latent variables. The reason we make this assumption is that observations $x$ has high complexity.
