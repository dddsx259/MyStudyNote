# 中文总结：PatchMatch

## 元信息

| 项 | 内容 |
|---|---|
| 标题 | PatchMatch: A Randomized Correspondence Algorithm for Structural Image Editing |
| 作者 | Connelly Barnes（Princeton）, Eli Shechtman（Adobe / UW）, Adam Finkelstein（Princeton）, Dan B Goldman（Adobe） |
| 会议 / 年份 | SIGGRAPH 2009（ACM TOG） |
| PDF 位置 | 本文件夹内同名 PDF |
| 课题语境 | MIT 6.S978 · Lec1：patch 对应 / 最近邻场 / 自相似驱动的结构图像编辑前史 |

**论文事实**：提出计算图像间（或区域间）**近似最近邻场（Approximate Nearest-Neighbor Field, NNF）** 的随机化算法，相对当时常用的 kd-tree+PCA 等加速约 **20–100×**，内存约少 **20×**，使基于双向相似度的重定向、补全、reshuffling 达到**交互速度**，并加入线/区域等直观约束。

---

## 与课题关联（Lec1）

接在 Efros–Leung（1999）之后的关键工程跃迁：

1. **核心对象从「逐像素条件采样」变成「稠密 patch 对应」**：对 $A$ 中每个 patch，在 $B$ 中找最像的 patch；整幅映射即 NNF。
2. **自然图像相干性**：好的偏移往往成片出现（大块拷贝自输入）——可**传播**好匹配。
3. **大数定律 + 随机搜索**：随机初始化时，「至少一个 patch 猜对偏移」的概率不低；再局部加密搜索即可扩散。
4. **编辑 = 反复求 NNF + 投票/EM**：补全、retarget、reshuffle 共用同一对应引擎。

对生成模型课：PatchMatch 展示「不学深度网络、只靠自相似检索」也能做强结构合成；后来的 Neural PatchMatch、attention 中的对应，都可对照「显式 NNF」。

## 背景与问题

### 三类结构编辑任务

| 任务 | 用户意图 | 计算机角色 |
|---|---|---|
| Retargeting | 改长宽比 | 自动重排内容，重要区域少变形 |
| Completion | 擦除一块 | 合成与周围协调的填充 |
| Reshuffling | 挪动某区域 | 其余部分自动接好 |

理想工具需：**灵活**（多种无缝操作）+ **够快**（试错交互）。非参数 patch 采样（Hertzmann, Wexler, Simakov 等）满足灵活，但全图 NNF 搜索太慢。

### 朴素复杂度

图像/区域 $M$ 像素，patch $m$ 像素：暴力 NNF 为 $O(m M^2)$。树方法 + 降维仍是瓶颈，且辅助结构内存 $O(M)$ 常数大。

### 三点洞察（论文事实）

1. **在偏移空间搜索**：patch 空间虽 $m$ 维，但只有 $O(M)$ 个真实 patch；直接在 2D 偏移上搜更省。
2. **利用图像结构**：相邻像素的最优偏移往往相近，应**协同**搜索（传播）。
3. **大数定律**：单个随机偏移很难准，但大图上总会有一些「碰巧很好」的种子。

## 方法与公式

### 1. NNF 定义

$$
f: A \mapsto \mathbb{R}^2,\qquad f(a)=b-a
$$

其中 $a$ 为 $A$ 中 patch 中心，$b$ 为 $B$ 中最近邻 patch 中心；$D$ 为 patch 距离（编辑里常用 L\*a\*b\* 上 SSD）。$f$ 存成与 $A$ 同尺寸的偏移数组。

### 2. 算法三阶段

**初始化**：均匀随机偏移，或由金字塔上一层上采样；可混用随机与上采样以防局部最优。

**迭代**（通常 **4–5** 次后基本收敛）：对每个 patch 交错做：

**(a) Propagation（传播）**  
奇数遍左→右、上→下：用左邻 $f(x-1,y)$ 与上邻 $f(x,y-1)$ 作为候选，取使 $D$ 更小者。偶数遍反向传播。直觉：若一点匹配正确且落在相干区域，其右下方会被「填」成同一平移。

**(b) Random search（随机搜索）**  
设当前最优 $v_0=f(x,y)$，试探

$$
u_i = v_0 + w\,\alpha^i R_i,\qquad R_i\sim\mathrm{Unif}([-1,1]^2)
$$

$w=$ 图像最大边长，$\alpha=1/2$（除非另注），直到半径 $<1$。在当前最优附近做指数收缩的随机扰动，跳出局部陷阱。

**效率技巧**：部分距离和可提前终止；方 patch + $L_q$ 时传播阶段距离增量可 $O(p)$ 更新（需存当前最优距离）。

**GPU**：传播与随机搜索分阶段并行；传播用 jump flood 变体（最大跳距 8、每距 4 邻域）。论文称 GPU 相对 CPU 约 **7×**（GeForce 8800 GTS）。

### 3. 收敛分析（要点）

- 极限下可收敛到精确 NNF；实践作**固定少量迭代的近似**。
- 随机初始化后，至少一个位置落在正确偏移邻域 $C$ 的概率约 $1-e^{-C}$（大 $M$）。
- 合成困难例（均匀背景上的独特区域）：期望迭代次数随分辨率趋于常数 $\sim M/(Cm)$ 量级（小特征相对尺寸 $\gamma=m/M$ 时展开）。
- 近似匹配时，多个「干扰项」反而提高找到足够好匹配的概率。

### 4. 编辑层：双向相似度（BDS）

沿用 Simakov et al.：

$$
d_{\mathrm{BDS}}(S,T)=\underbrace{\frac{1}{N_S}\sum_{s\subset S}\min_{t\subset T}D(s,t)}_{\text{completeness}}+\underbrace{\frac{1}{N_T}\sum_{t\subset T}\min_{s\subset S}D(t,s)}_{\text{coherence}}
$$

- Completeness：输出尽量覆盖输入视觉信息（好摘要）；
- Coherence：输出局部都应在输入中找得到（少伪影）。

优化：EM 风格——E：算 NNF + patch 投票；M：平均得新图。多尺度渐进缩放 / 上采样避免坏局部最优。仅保留 coherence、令 $T=$ 洞、$S=$ 洞外 → 即 Wexler 式补全。

### 5. 用户约束（改搜索域 / 校正偏移）

| 类型 | 作用 |
|---|---|
| 搜索空间约束 | 洞内标签点只在洞外同标签区域搜索（引导结构/纹理） |
| 模型约束 | 直线保持直、区域均匀/平移缩放等；每轮 EM 后 RANSAC 估模型并投影校正 NNF |
| Hard constraints | 固定某区 NNF 到指定位置（reshuffle）；洞初始化可选 swap / interpolate / clone |

**论文事实**：相对 kd-tree+PCA，典型 **20–100×** 更快、约 **20×** 更省内存；$4\times 4$ patch 加速约 7–35×，$14\times 14$ 可达 300×+。

### 近似误差（相对精确 NN 的 RMS 差，5 次迭代）

| 图像对类型 | 均值误差（灰阶，/256） | 95 分位 |
|---|---|---|
| 相似（编辑输入输出、立体、相邻帧等） | 0.2–0.5 | 0.5–2.5 |
| 不相似 | 0.6–1.5 | 0.9–6.0 |

合成测试：$m=20^2$ 区域、$M=2000^2$ 时，5 次迭代后以很高概率收敛。

编辑质量：与 seam carving、Wang et al. 等对照以**定性图**为主（保直线、少压扁重复元素、可挪人腾空间等）。主文**未报告**统一 PSNR 表。

## 消融 / 对照

- 初始化：纯上采样易陷局部最优 → 早期随机迭代再与上采样按 $D$ 合并。
- 传播方向：奇偶反向扫描。
- 并行变体：多核上误差可比，单核约慢 2.5×，随核数近似线性。
- vp-tree：精确 NN 更快，但近似+PCA 时不如 kd-tree，故未作主对比。

## 优势与局限

### 优势

- **论文事实**：交互级结构编辑；约束统一进搜索；内存几乎只需原图量级；任意距离度量易改。
- **批判性分析**：把「相干性」从显式 MRF 邻接项变成搜索启发式，工程上极划算。

### 局限

- **论文事实**：病态合成例收敛差；极端编辑可能 ghosting/feathering；无显式邻接平滑项（与 stereo/光流 MRF 不同）。
- **批判性分析**：质量依赖随机种子与约束；加速数字相对特定基线；视频/3D 仅为展望。

---

## 可迁移启示

1. **稠密对应是 patch 合成的瓶颈**——算法贡献在对应，不在新的图像先验形式。
2. **传播 + 随机多尺度扰动** ≈ 利用数据相干性的坐标下降式搜索。
3. Completeness ↔ Coherence 双向目标，是「摘要/重定向」与「补全」的统一语言。
4. 约束 = 限制允许的偏移集合，比事后惩罚更直接。
5. 对照现代方法：PatchMatch ≈ 无学习的 attention/retrieval；深度学习后来把 $D$ 与特征表示学出来，但「NNF + 投票」骨架仍常见。

---

## 贡献与一句话总结

**贡献（论文事实）**：

1. 随机化近似 NNF：初始化 → 传播 → 指数随机搜索，附收敛分析；
2. 据此实现交互式 retarget / completion / reshuffle；
3. 线、区域、硬约束等用户控制，统一进优化。

**一句话总结**：自然图像中好的 patch 对应往往成片出现——先靠随机碰上几个好偏移，再传播并局部乱搜，就能以远低于树搜索的代价得到整幅近似最近邻场，从而把结构图像编辑做成可交互工具。

---

## 五段式精炼要点

1. **问题**：结构编辑依赖反复全图 patch 最近邻，太慢无法交互。
2. **方法**：在偏移域上随机初始化，传播相干匹配，并做指数半径随机搜索。
3. **结果**：约 20–100× 加速、内存大降；近似误差通常亚灰阶至数灰阶；支撑约束补全与重定向等。
4. **编辑层**：BDS / Wexler 式 EM + 搜索域与模型约束。
5. **遗产**：成为图像修复、立体、去噪等众多「非局部 patch」流水线的默认对应引擎之一。
