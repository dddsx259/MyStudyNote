# 中文总结：Texture Synthesis by Non-parametric Sampling

## 元信息

| 项 | 内容 |
|---|---|
| 标题 | Texture Synthesis by Non-parametric Sampling |
| 作者 | Alexei A. Efros, Thomas K. Leung（UC Berkeley） |
| 会议 / 年份 | ICCV 1999 |
| PDF 位置 | 本文件夹内同名 PDF |
| 课题语境 | MIT 6.S978 Deep Generative Models · Lec1：自然图像自相似 / 非参数采样 / 示例驱动生成与修复前史 |

**论文事实**：提出一种基于 **Markov Random Field（MRF）** 假设的纹理合成算法——从样例纹理向外「生长」新图，**一次合成一个像素**；给定当前邻域，在样例图中查找所有相似邻域，对其中心像素做直方图并采样。随机性主要由邻域窗口宽度这一个参数控制。方法特别适合有约束的合成（如 hole-filling）。

---

## 与课题关联（Lec1）

Lec1 关心「自然图像 / 纹理从哪来、如何生成」。本文是深度生成模型之前的经典节点：

1. **自相似 + 示例**：不训练参数模型，直接在样例图里「抄」局部模式——新像素的条件分布由数据中的相似邻域经验估计。
2. **MRF 局部性**：像素只依赖邻域窗口；窗口尺度 ≈ 最大「规整」纹理元素（texel）尺度。
3. **非参数采样**：不建显式 $p$（不像 FRAME / 滤波器直方图匹配），查询式构造条件分布——与后来的 patch 匹配、exemplar-based inpainting、乃至检索式生成一脉相承。
4. **约束合成**：洞填充、边界外推、前景去除等，把「生成」变成「在已知边界条件下补全」。

对后续课程：可把本文看成「条件生成」的朴素版本——条件是已合成邻域，生成器是样例库上的最近邻式采样。PatchMatch、Image Quilting、Exemplary Inpainting 都建立在类似直觉上。

---

## 背景与问题

### 问题形式化

**论文事实**：把纹理定义为无限 2D 平面上、在某尺度具有**平稳分布**的视觉模式。给定有限样例，目标是合成「同一纹理」的其他样本。无额外假设时问题不适定（同一块样例可来自无穷多种纹理）。常用假设：样例足够大以捕获平稳性，且 texel 的大致尺度已知。

真实纹理往往介于「规则重复」与「纯随机」之间，需要同一模型覆盖中间地带。

### 先前路线的不足（论文事实）

| 方法 | 思路 | 局限（作者观点） |
|---|---|---|
| Zhu et al. FRAME + Gibbs | 显式 MRF + 采样 | Gibbs 极慢，收敛难判断 |
| Heeger–Bergen | 多尺度滤波响应直方图匹配 | 对砖墙等结构化纹理不够强 |
| De Bonet | 多分辨率父子依赖随机化 | 大图靠平铺样例，隐含可平铺假设；随机性参数对结构纹理不直观 |
| Simoncelli–Portilla | 小波联合统计 | 部分高度结构化模式仍缺高频 |

### 核心灵感：Shannon 的 $n$-gram

**直觉**：英文文本可用 $n$-gram Markov 链：前 $n$ 个字符决定下一个字符的分布；从书中统计表再反复采样，能得到「像英文」的字符串（MARK V. SHANEY）。本文把这一思想扩展到二维：合成单元 = 像素；上下文 = 邻域窗口；概率表太大无法显式建，改为**每次现场查询样例图**（非参数）。

## 方法与公式

### 1. MRF 假设（必懂）

**一句话直觉**：给定邻域窗口内的像素，中心像素与图像其余部分条件独立——「远处」不直接管「这里长什么样」，只通过邻域间接影响。

邻域取以像素 $p$ 为中心的方形窗口 $\omega(p)$，宽度 $w$ 是用户设定的自由参数：

- 纹理在高频较规整、低频较随机时，$w$ 应覆盖**最大规整特征**的尺度；
- $w$ 越大 → 合成越「有序 / 像样例结构」；$w$ 越小 → 越随机。

### 2. 单像素合成

设正在合成的图像为 $I$，样例为 $I_{\mathrm{sample}}$（来自真实无限纹理的有限观测）。像素距离 $d(\cdot,\cdot)$ 度量两块邻域的感知差异。

理想情况下，若 $\omega(p)$ 在样例中所有出现构成集合 $\Omega(p)$，则 $p$ 的条件分布可用 $\Omega(p)$ 中各中心像素的直方图估计。有限样例下完美匹配可能不存在，故用启发式：

1. 在 $I_{\mathrm{sample}}$ 中找与 $\omega(p)$ 距离最小的邻域 $\omega_{\mathrm{best}}$；
2. 收集所有满足
   $$
   d\bigl(\omega(p),\,\omega\bigr) < (1+\varepsilon)\,d\bigl(\omega(p),\,\omega_{\mathrm{best}}\bigr)
   $$
   的邻域（**论文事实**：实现中 $\varepsilon=0.1$）；
3. 对这些邻域的中心像素构成直方图，再均匀或按距离加权采样，得到 $p$ 的值。

**距离**：归一化 SSD，再乘二维高斯核，使靠近中心的像素失配代价更大——优先保住局部结构。

脚注提醒：若邻域除中心外全已知，对多数非高度随机纹理，$p$ 的条件分布近似 δ（单像素很少单独成「特征」）；真正工作时邻域往往只有部分已知。

### 3. 整图 / 空洞：向外生长启发式

联合考虑所有未知像素不可行。作者采用 Shannon 式启发式：

- 无约束合成：从样例中随机取 $3\times 3$ **种子**，向外一层层生长；
- 填洞：从洞边界向内生长。

对邻域中**尚未合成**的像素：只在已知位置上匹配，并用已知像素个数归一化误差。该启发式不保证后续填满邻域后条件分布仍有效，但实践中效果好；用 Gibbs 迭代 refine 多数纹理几乎无增益——作者据此认为启发式已接近目标条件分布。

## 数据 / 参数 / 反传需求

| 项 | 内容 |
|---|---|
| 训练 | **无参数训练**；唯一「数据」是样例图本身 |
| 用户参数 | 邻域窗口宽度 $w$（主参数）；$\varepsilon=0.1$；高斯加权 SSD |
| 梯度 / 反传 | 无；纯搜索 + 采样 |
| 计算 | 每像素在样例上扫邻域匹配；作者称算法「quite slow」，效率为未来工作 |

## 优势与局限

### 优势

- **论文事实**：单一简单模型覆盖从随机到结构化的宽纹理谱；约束合成形状自由；强调保局部结构（直线延续等）。
- **批判性分析**：非参数查询避开了错误参数族；对 Lec1，「生成 = 在数据中条件采样」的叙事非常清晰。

### 局限

- **论文事实**：仅正面平行纹理；可能垃圾生长或 verbatim copy；速度慢；窗口需人手选。
- **批判性分析**：逐像素 + 全图搜索复杂度高；因果生长顺序引入误差累积；无全局一致性目标（后来 Wexler / PatchMatch 优化填补）。未报告定量质量，复现依赖观感。

---

## 可迁移启示

1. **条件分布可由数据邻域经验估计**——不必先写闭式 $p(x)$。
2. **局部自相似**是自然图像生成的强先验：洞里的内容往往能在洞外找到「差不多」的邻域。
3. **尺度参数（窗口）= 结构 vs 随机的旋钮**——类似后来感受野 / patch size。
4. 像素级合成 → 后续转向 **patch / quilting** 提速并减接缝伪影。
5. 与现代生成模型对照：本文是「检索式条件采样」；VAE/GAN/扩散是「参数化分布学习」——问题相同（从样例长出新图），表示不同。

---

## 贡献与一句话总结

**贡献（论文事实）**：

1. 将 Shannon $n$-gram 思想二维化，给出基于 MRF + 非参数邻域查询的像素生长合成算法；
2. 用单一窗口参数直观控制随机性，覆盖广谱纹理；
3. 特别适配 hole-filling 等约束合成，并讨论遮挡填补、边界外推、压缩、前景去除、运动纹理等应用。

**一句话总结**：在 MRF 局部性假设下，新像素的值不必由参数模型给出，而可直接在样例纹理中查找相似邻域并对其心像素采样——纹理合成变成「带上下文的非参数抄写」。

---

## 五段式精炼要点

1. **问题**：从有限纹理样例合成同分布新样本（及约束填洞），需同时覆盖规则与随机纹理。
2. **方法**：MRF + 方形邻域；按已知邻域在样例中找近邻集合；对中心像素直方图采样；从种子/边界向外生长。
3. **结果**：定性上对 Brodatz 与真实纹理效果好；$w$ 与感知随机性一致；可做约束填洞与图像外推。
4. **代价**：慢；可能垃圾生长或 verbatim copy；仅正面平行；缺定量指标。
5. **地位**：非参数示例驱动合成的奠基作之一，直接启发后续 patch 合成与图像修复。
