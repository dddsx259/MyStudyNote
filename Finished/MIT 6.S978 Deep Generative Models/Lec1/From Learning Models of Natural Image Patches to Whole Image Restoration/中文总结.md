# 中文总结：From Learning Models of Natural Image Patches to Whole Image Restoration（EPLL）

## 元信息

| 项 | 内容 |
|---|---|
| 标题 | From Learning Models of Natural Image Patches to Whole Image Restoration |
| 作者 | Daniel Zoran, Yair Weiss（Hebrew University of Jerusalem） |
| 会议 | ICCV 2011 |
| 常用简称 | **EPLL**（Expected Patch Log Likelihood） |
| PDF 位置 | 本文件夹内同名 PDF |
| 课题语境 | MIT 6.S978 Deep Generative Models · Lec1：自然图像先验、patch 模型、深度生成模型「前史」 |

**论文事实**：本文回答三个问题——(1) 对自然图像 patch 给出更高似然的先验，是否也更好做 patch 复原？(2) 这样的 patch 先验能否用于整图复原？(3) 能否学到更好的 patch 先验？答案依次为：是；提出 EPLL 通用框架；提出无约束的 GMM patch 先验，并在去噪/去模糊等任务上表现突出。

---

## 与课题关联（Lec1）

Lec1 关心的是：**自然图像长什么样、如何用可学习的概率模型刻画**，以及这些模型如何服务于复原（denoising / deblurring / inpainting）。EPLL 处在「深度生成模型」之前的关键节点上：

1. **先验在 patch 上学习，而不是直接在整图上学习**——整图维数太高，似然与 MAP 往往不可算；小 patch 上则可以学到显式概率模型并算 MAP。
2. **似然与复原质量相关**——不是「随便一个正则项」，而是把「模型对数据有多信」与「去噪有多好」连起来。
3. **整图目标不是简单的 patch 平均**——多数当时方法：各 patch 独立复原再平均；EPLL 要求**复原后图中每个重叠 patch 在先验下都尽量可能**。
4. **GMM 作为强先验**——在深度网络成为默认生成器之前，一个「朴素」的高斯混合就能在通用先验里压过 FoE、全局 KSVD，并对标 BM3D / LLSC。

对后续课程：EPLL 的「先验 + 数据项 + 交替优化」可对照后来的能量最小化、plug-and-play、以及「生成模型当先验」的思路；GMM 的「按分量选字典再稀疏」也预示了结构化稀疏与分段线性估计。

更具体地说，Lec1 若把「生成模型」理解为「能给样本打分（密度/能量）或能采样的模型」，则本文的 GMM 是**显式密度**：$p(x)$ 可直接写出来并用于 MAP。这与后来用 CNN/扩散模型隐式定义先验、再塞进逆问题求解器是同一问题族的不同实现。读本文时建议抓住两条主线：**什么先验算「好」**（似然），以及 **局部先验如何约束整图**（EPLL，而非平均）。

## 背景与问题

### 为什么需要图像先验？

图像复原通常写成：观测 $y$ 由未知干净图 $x$ 经已知退化得到，例如加性噪声、模糊卷积、缺像素掩码等。仅靠 $y$ 往往**不适定**（解不唯一或不稳定），因此需要先验 $p(x)$：「自然图像更可能长什么样」。

**直觉**：先验 = 对解空间的偏好。没有先验，去噪时任意高频「噪声样」与「纹理样」难以区分。

### 为何落到 patch？

**论文事实**：整图先验学习/推断/优化计算代价极高；许多工作因此在小 patch（如 $8\times 8$）上学习先验。patch 上闭式或易算的 log-likelihood、BLS、MAP 更现实。

**批判性分析**：patch 独立性假设与真实图像的全局结构不符；如何把局部好模型「拼」回整图，是本文核心工程问题，也是后来非局部方法、整图 MRF、深度学习端到端复原不断重访的问题。

### 朴素用法的失败模式（Figure 2）

同一直方图先验下：

| 策略 | 现象 |
|---|---|
| 不重叠切块 → 各块 MAP → 拼回 | 块边界伪影严重 |
| 重叠切块 → 取中心像素 | 仍可能产生先验下极不可能的局部模式 |
| 重叠切块 → 像素平均（patch averaging, PA） | 更好，但平均会**造出新 patch**，这些 patch 在先验下往往仍不像自然 patch |
| **EPLL** | 同样先验下伪影更少，复原 patch 更「像」先验 |

核心直觉：**最终整图里「随便抽一个 patch」都应当在先验下有高 log-likelihood**，同时整图仍要贴近观测模型。

## 方法与公式

### 1. 似然、MAP、BLS（必懂）

设干净 patch 为 $x$，观测为 $y$（例如 $y=x+\text{noise}$）。

- **似然（likelihood）** $p(y\mid x)$：给定干净图，观测有多可能。去噪时常取高斯噪声：$p(y\mid x)\propto\exp(-\|y-x\|^2/(2\sigma^2))$。
- **先验（prior）** $p(x)$：干净 patch 本身有多「自然」。
- **后验** $p(x\mid y)\propto p(y\mid x)\,p(x)$。
- **MAP**：$\hat x=\arg\max_x p(x\mid y)=\arg\max_x[\log p(y\mid x)+\log p(x)]$——找后验峰值。
- **BLS（Bayesian Least Squares）**：在平方损失下最优是后验均值 $\mathbb{E}[x\mid y]$。

**一句对照**：似然管「跟观测合不合」；先验管「像不像自然图像」；MAP 取折中后的「最可能干净图」；BLS 取「平均意义下最优」。

本文 Section 2 在**独立 patch**上比较：模型对未见自然 patch 的 log-likelihood 越高，MAP 去噪 PSNR 越好（Figure 1）。

### 2. EPLL 目标

将图像向量化记为 $x$，用矩阵 $P_i$ 抽出第 $i$ 个重叠 patch。定义：

$$
\mathrm{EPLL}_p(x)=\sum_i \log p(P_i x)
\qquad (1)
$$

若均匀随机选一个 patch 位置，这（差一个 $1/N$ 因子）就是该 patch 的**期望 log-likelihood**。

退化模型写成二次数据项 $\|Ax-y\|^2$（去噪：$A=I$；非盲去模糊：$A$ 为卷积矩阵；修复：$A$ 为对角掩码）。最小化：

$$
f_p(x\mid y)=\frac{\lambda}{2}\|Ax-y\|^2-\mathrm{EPLL}_p(x)
\qquad (2)
$$

**论文事实（重要澄清）**：$\mathrm{EPLL}_p(x)$ **不是**整图的真实 log-probability——重叠 patch 会「重复计数」。作者明确说：我们并不声称在近似全局 $\log p(x)$，而只是要求局部边际在先验下高。

**批判性分析**：这与 composite likelihood / 有向模型等「用局部近似全局」路线不同；优点是学习简单、先验可更丰富；代价是缺少对整图归一化常数与全局一致性的严格概率解释。

### 3. Half-Quadratic Splitting（半二次分裂）

直接优化 (2) 很难。引入辅助变量 $\{z_i\}$（每个重叠 patch 一个），改写为：

$$
c_{p,\beta}(x,\{z_i\}\mid y)=\frac{\lambda}{2}\|Ax-y\|^2+\sum_i\left(\frac{\beta}{2}\|P_i x-z_i\|^2-\log p(z_i)\right)
\qquad (3)
$$

**直觉**：

- $\beta$ 小：允许 $z_i$ 与当前图上的 patch $P_ix$ 有差距，先把各 $z_i$ 「拉」到先验喜欢的样子；
- $\beta\to\infty$：强迫 $P_ix=z_i$，于是 (3) 的解逼近 (2)。

固定 $\beta$ 时交替两步：

**步骤 A — 固定 $\{z_i\}$ 求 $x$（闭式）**

$$
\hat x=\left(\lambda A^\top A+\beta\sum_j P_j^\top P_j\right)^{-1}\left(\lambda A^\top y+\beta\sum_j P_j^\top z_j\right)
\qquad (4)
$$

去噪时 $A=I$：$\hat x$ 就是噪声观测与「辅助 patch 叠回图」之间的加权平均。

**步骤 B — 固定 $x$ 求每个 $z_i$**

对每个 $i$，在「观测」$P_ix$、噪声尺度 $\sqrt{1/\beta}$ 下，对先验 $p$ 做 **MAP（或近似 MAP）**。因此：**任意能做 patch MAP 的先验都能插入本框架**。

外层：通常 4–5 次内迭代，然后增大 $\beta$。$\beta$ 可手工在训练集上调，或（去噪时）用噪声估计设 $\beta=1/\sigma^2$。Figure 3 表明：即使用 BLS 代替 MAP，只要子问题代价下降，原代价 $f_p$ 也可下降。

**运行时（论文事实）**：约为简单 patch averaging 的 4–5 倍（取决于迭代次数）。

**Half-quadratic 再白话一点**：目标里同时有「整图 $x$」和「先验喜欢的局部 $z$」，两者通过 $\|P_ix-z_i\|^2$ 耦合。直接联立很难，于是先假装 $z$ 已知去更新 $x$（这是线性最小二乘，可解），再假装 $x$ 已知去更新每个 $z$（这就是标准的 patch 去噪/MAP）。$\beta$ 是耦合弹簧的劲度：一开始弹簧软，允许 $z$ 大胆按先验变形；后面弹簧变硬，强迫整图与这些净化后的窗口一致。这就是为什么它叫 splitting——把难问题拆成两个熟悉的子问题。

### 4. 任务特例（Section 3.1.3）

| 任务 | $A$ | 备注 |
|---|---|---|
| 去噪 | $I$ | $\lambda$ 与 $\sigma$ 相关（实验中 $\lambda=N/\sigma^2$，$N$ 为 patch 像素数） |
| 非盲去模糊 | 卷积矩阵 | 核已知 |
| 修复 | 对角 0/1 掩码 | 缺像素可视为「无限噪声」，其余为零噪声 |

若初始化 $x\leftarrow y$，并设 $\lambda=0$、$\beta=1/\sigma^2$ 只迭代一步，则退化为简单 patch averaging；EPLL 的关键是 **$\lambda\neq 0$ 且多轮增大 $\beta$**。

### 5. GMM patch 先验

对去 DC 后的 patch，学习有限高斯混合（**不**强加常见的对角/结构化约束）：

$$
\log p(x)=\log\left(\sum_{k=1}^{K}\pi_k\,\mathcal{N}(x\mid\mu_k,\Sigma_k)\right)
\qquad (5)
$$

用 **EM** 学 $\pi_k,\mu_k,\Sigma_k$。论文最终用 $K=200$，均值置零（无约束均值时学到的均值也接近 0），全协方差；$2\times 10^6$ 个 $8\times 8$ patch，训练约 30h（未优化 MATLAB）。

**BLS**：后验仍是 GMM，可闭式。  
**近似 MAP**：

1. 算条件混合权重 $\pi'_k=P(k\mid y)$；
2. 取 $k_{\max}=\arg\max_k \pi'_k$；
3. 对该分量做 Wiener：

$$
\hat x=(\Sigma_{k_{\max}}+\sigma^2 I)^{-1}(\Sigma_{k_{\max}} y+\sigma^2 I\mu_{k_{\max}})
$$

**直觉（为何强）**：零均值 GMM 下，样本近似由所属分量协方差的主特征向量张成；200 个分量组成「字典」，但**同一时刻只允许同一分量的基一起激活**——极稀疏且激活集高度结构化，不同于 ICA/稀疏编码的任意支撑集。特征向量呈现遮挡、纹理边界、边缘等结构（Figure 6），而不只是典型 Gabor。

## 消融与对照

论文没有现代意义上的「逐模块消融表」，但有清晰对照轴：

1. **先验质量**：Ind → MVG → PCA → ICA → GMM（似然与 PSNR 同步上升）。
2. **聚合方式**：PA vs EPLL（Figure 4b / Table 1）：EPLL 全面更好。
3. **优化细节**：固定 $\beta$ 日程 vs 从当前估计自动估 $\beta$（Figure 3）；MAP vs BLS 子问题——代价仍可下降。
4. **通用 vs 图像自适应**：Table 2a/2b。
5. **任务迁移**：去噪上可对标非局部方法；去模糊上通用先验优势更清晰。

未系统报告：分量数 $K$、patch 大小、$\beta$ 日程敏感性的完整曲线（$\beta$ 仅在 5 张图上手工调）。

## 优势与局限

### 优势（论文事实 + 简评）

- **即插即用**：任何可做（近似）MAP 的 patch 先验都能接入。
- **学习简单**：只需学 patch 模型，不必学整图 $P(x)$ 或难处理的 MRF 配分函数。
- **效果强**：GMM+EPLL 在通用先验上领先；去模糊相对 hyper-Laplacian 方法有明显 PSNR 增益。
- **概念清晰**：把「高似然先验」与「好复原」实证挂钩，推动「先把局部生成模型学好」。

### 局限

- EPLL **不是**规范的整图概率模型（双重计数）。
- Half-quadratic 的 $\beta$ 日程依赖手工/启发式；全局最优 **无保证**（作者用实验观察代价下降）。
- GMM 近似 MAP 只取一个分量，可能丢掉多峰后验信息（虽与 BLS 数值接近，Table 1）。
- 计算：约 300s/图（2011 MATLAB）；现代加速 **未报告**。
- Inpainting 定量结果在补充材料，正文 **未报告**数字。
- 与 BM3D/LLSC 在部分噪声水平上仍互有胜负；「全面碾压非局部」并不成立。

## 可迁移启示（面向 Lec1 / 生成建模）

1. **局部显式密度模型**仍可很强：GMM 不是「过时玩具」，而是可解释、可算 MAP 的生成先验。若课程后面讲 VAE/归一化流/扩散，可把它们看成「把这里的 $p(x)$ 换得更强」，而复原时仍可能回到「先验分数 + 数据项」的优化或采样。
2. **似然是有用的模型选择信号**——至少在本文设定下与复原相关；对照今天：ELBO/NLL 与下游任务未必总一致，但「密度好不好」仍值得测。本文的价值在于：**在可控模型族里把这条链路测清楚了**。
3. **从 patch 到整图**：独立推理 + 平均 ≠ 好；需要耦合约束（EPLL / HQS / 后来的 PnP、扩散后验采样等）。看到任何「分块处理再拼回」的系统，都应问：拼回后的局部是否仍落在模型高概率区？
4. **结构化稀疏**：GMM 的「同分量共激活」是硬约束稀疏，启发「先验应编码哪些模式能一起出现」。这比「系数大多为零」更强——零的模式本身也有结构。
5. **通用先验的价值**：去噪可靠同图统计；去模糊/缺信息更重「自然图像长什么样」的外部知识——与「预训练生成模型当先验」同构。做课题选型时：噪声可自相似抵消的任务，非局部/test-image 自适应往往够用；信息被卷积或掩码严重破坏时，外部学到的先验更关键。

## 贡献与一句话总结

**贡献（论文事实）**：

1. 实证：更高 patch 似然 ↔ 更好 patch/整图复原（在所比较模型族内）。
2. 提出 EPLL + half-quadratic splitting，把任意 patch MAP 先验接到整图复原。
3. 提出无约束全协方差 GMM patch 先验，配合 EPLL 在去噪/去模糊等任务上达到当时一流水平。

**一句话**：用「期望 patch 对数似然」把好学的局部先验接到整图复原上，再配一个强 GMM，就能在不学整图模型的情况下做出接近甚至超过复杂方法的复原。

## 五段式精炼要点

1. **问题**：整图先验难学难推；patch 先验好学，但独立复原再平均会造出「先验不喜欢」的整图。  
2. **关键量**：$\mathrm{EPLL}=\sum_i\log p(P_ix)$，与数据项组成目标 (2)；用 HQS 引入 $z_i$，交替「整图最小二乘」与「各 patch MAP」。  
3. **先验**：200 分量全协方差 GMM（去 DC，$8\times 8$），近似 MAP = 选最可能分量 + Wiener。  
4. **证据**：Table 1 似然与 PSNR 同升；Table 2 通用先验 SOTA、对标 BM3D/LLSC；去模糊两核约 +1.3 dB。  
5. **课上定位**：自然图像局部生成建模的经典范式——显式密度 + 逆问题优化；是深度生成先验与 PnP 路线的重要前史。
