## 0. 先建立世界观（比公式更重要）

### 我们最终要什么产品？

| 产品 | 含义 | VAE 给不给 |
|---|---|---|
| **采样** | 无条件或条件地吐新 $x$ | 给：从 $p(z)$ 采再解码 |
| **密度** | 问 $p(x)$ 多大 | 一般**不精确给**（只有 ELBO 下界） |
| **推断** | 看到 $x$ 后 $z$ 是什么 | 给近似：$q_\phi(z\mid x)$ |

### 三块地图

1. **VAE**：积不出来的 $\log p(x)$ → 可优化的 ELBO  
2. **EM**：同一下界思想，换一套优化方式  
3. **VQ-VAE**：把 $z$ 变成离散码，当 tokenizer；联合分布另建模型

## 1. 隐变量模型（幻灯 3–10）

### 生成故事（现实意义）

想象拍照：先有「姿态、光照、物种…」等隐藏因素 $z$，再经「世界/渲染」变成像素 $x$。

- $z\sim p(z)$：因素本身简单（我们假定）  
- $x\sim p_\theta(x\mid z)$：渲染复杂，用网络表示  

我们真正想拟合的是边缘：

$$
p_\theta(x)=\int p_\theta(x\mid z)\,p(z)\,dz
$$

| | |
|---|---|
| **困难** | 高维积分算不出 ⇒ 不能直接对 $\log p_\theta(x)$ 做梯度下降 |
| **这一设定买到什么** | 把「复杂 $x$」拆成「简单 $z$ + 可学渲染」；采样时只需先采 $z$ |
| **若不引入 $z$** | 必须直接在像素空间建完整 $p(x)$（极难）；或放弃显式概率（如部分 GAN） |

### 用什么衡量「分布学得好」？（幻灯 7）

最小化 $D_{\mathrm{KL}}(p_{\mathrm{data}}\|p_\theta)$ $\Leftrightarrow$ 最大化

$$
\mathbb{E}_{x\sim p_{\mathrm{data}}}[\log p_\theta(x)]
=\sum_x p_{\mathrm{data}}(x)\log p_\theta(x)
$$

（右边就是期望的定义：按数据分布加权平均 $\log p_\theta$。）

**现实意义**：让模型在「真数据常出现的地方」打高分；漏掉某个数据模态会被 KL/似然狠狠惩罚。

**KL 一句话**：$D_{\mathrm{KL}}(q\|p)=\mathbb{E}_q[\log q-\log p]$——样本来自 $q$，却用 $p$ 当编码本，平均多付多少代价。$q$ 有质量而 $p\approx 0$ 的地方最痛。不对称，不是欧氏距离。

## 2. 为何引入任意 $q(z)$？（幻灯 11–19）——整讲最关键的「目的」

### 推导（你可以验证代数）

对任意 $q(z)$：

$$
\log p_\theta(x)
=\mathbb{E}_{q}\big[\log p_\theta(x,z)-\log q(z)\big]
+D_{\mathrm{KL}}\big(q(z)\,\|\,p_\theta(z\mid x)\big)
$$

记第一项为 **ELBO**，第二项 $\ge 0$，故

$$
\log p_\theta(x)=\mathrm{ELBO}+D_{\mathrm{KL}}(q\|p(z\mid x))\ge\mathrm{ELBO}
$$

### 目的模板（请盯住这里）

| | |
|---|---|
| **困难** | $\log p(x)$ 与真后验 $p(z\mid x)$ 都不可算 |
| **引入 $q$ 买到什么** | 把问题改成：优化一个**可设计成可算/可估**的下界 ELBO；间隙就是「$q$ 离真后验有多远」 |
| **若不引入 $q$** | 卡在积分上，深度隐变量模型几乎无法用最大似然训练 |

再拆 ELBO 里两项谁可算：

| 量 | 通常 |
|---|---|
| $p(z)$、$p_\theta(x\mid z)$、$q(z)$ | 可设计成可算 |
| $p_\theta(x)$、$p_\theta(z\mid x)$ | 不可算 |

**现实意义**：$q$ 是你的「可控旋钮」——选得越像真后验，ELBO 越贴真 $\log p(x)$；选得很烂，你仍在训练，但优化的是一个很松的下界（自我感觉良好、实际似然很差）。

## 3. 变成 VAE：网络化的 $q$（幻灯 20–30）

### 3.1 编码器 = 摊销的近似后验

令 $q(z)=q_\phi(z\mid x)$（encoder 输出分布参数），$p(z)$ 取简单先验（常 $\mathcal{N}(0,I)$）：

$$
\mathrm{ELBO}(x)
=\mathbb{E}_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]
-D_{\mathrm{KL}}\big(q_\phi(z\mid x)\,\|\,p(z)\big)
$$

训练最小化：

$$
\mathcal{L}(x)
=\underbrace{-\mathbb{E}_{q_\phi}[\log p_\theta(x\mid z)]}_{\text{重建：像不像原图}}
+\underbrace{D_{\mathrm{KL}}(q_\phi(z\mid x)\|p(z))}_{\text{正则：编码别飞出先验}}
$$

| | |
|---|---|
| **困难** | 每个 $x$ 若单独做昂贵推断，$N$ 很大时不可扩展 |
| **网络 $q_\phi(z\mid x)$ 买到什么** | **摊销（amortized）推断**：一次前向 ≈ 对这张图做后验近似；可与 $\theta$ 一起 SGD |
| **若不用摊销** | 经典 VI 常对每个数据点单独优化局部变分参数，难以及深度生成模型规模 |

```text
x → encoder q_φ(z|x) → 采样 z → decoder p_θ(x|z) → x′
              ↓
         KL(q ‖ p(z))
```

### 3.2 重建项为何常是 L2？

若 $p_\theta(x\mid z)=\mathcal{N}(g_\theta(z),\sigma^2 I)$（$\sigma$ 固定），则 $-\log p\propto \|x-g_\theta(z)\|^2$。

| | |
|---|---|
| **困难** | 要算 $\mathbb{E}_{q}[\log p(x\mid z)]$ |
| **买到什么** | 用「解码再比 MSE」实现似然项；一轮 MC 采样估期望（SGVB） |
| **若不写概率、只写 MSE** | 仍可当 AE 训，但失去与 ELBO/似然的严谨联系，也难接「从先验采样生成」的概率解释 |

二值 MNIST → Bernoulli + BCE（同一逻辑：NLL）。

### 3.3 KL 正则的现实意义

高斯–高斯时 KL 有闭式（pset1）：

$$
D_{\mathrm{KL}}=\frac12\sum_j\big(\mu_j^2+\sigma_j^2-\log\sigma_j^2-1\big)
$$

| | |
|---|---|
| **困难** | 若只优化重建，encoder 可把 $z$ 放到任意怪异区域，decoder 死记硬背 |
| **KL 买到什么** | 强迫每个 $q_\phi(z\mid x)$ 待在先验附近 ⇒ 无条件生成时从 $p(z)$ 采样才「落在解码器见过的区」 |
| **若去掉 KL** | 常退化成普通 AE：重建很好，从 $\mathcal{N}(0,I)$ 采样往往出垃圾（潜空间有大片空洞） |

### 3.4 重参数（幻灯 28–29）

$$
\varepsilon\sim\mathcal{N}(0,I),\quad z=\mu+\sigma\odot\varepsilon
$$

| | |
|---|---|
| **困难** | 「从 $\mathcal{N}(\mu,\sigma)$ 采样」对 $\mu,\sigma$ 不可直接反传 |
| **买到什么** | 随机性全进 $\varepsilon$；对 $(\mu,\sigma)$ 的路径可微 ⇒ 可用反向传播训整个 VAE |
| **若不用重参数** | 只能用高方差的得分函数估计等，深度网很难训稳 |

### 3.5 生成时为什么丢掉 encoder？

1. $z\sim p(z)$  
2. $x=g_\theta(z)$  

| | |
|---|---|
| **困难** | 生成时没有「真实 $x$」可编码 |
| **买到什么** | 用先验当「创意来源」，解码器当渲染器 |
| **若生成时仍依赖 encoder** | 只能重建/插值已有数据，不能无条件新样本 |

## 4. 「分布的自编码」视角（幻灯 35–42）

VAE 不是只学点到点的 $x\mapsto x'$，而是学**分布之间的运输**：

| 部件 | 现实意义 |
|---|---|
| $q_\phi(z\mid x)$ | 每张图变成潜空间里一小团「云」 |
| 聚合 $q_\phi(z)$ | 所有云叠起来的整体 |
| $p(z)$ | 希望整体云堆贴紧它 |
| $p_\theta(x\mid z)$ | 云上的点都能解码成像样的图 |

MNIST 2D 可视化：相邻数字的云应重叠、填满先验支持集——否则插值会穿过「没人教过的 $z$」。

**批判性提醒（幻灯点到 InfoVAE）**：压 $D_{\mathrm{KL}}(q(z\mid x)\|p(z))$ **不等于**保证聚合 $q(z)\approx p(z)$。这是「训练目标」与「生成时真正采样的分布」之间的缝隙。

## 5. 与 EM 的关系（幻灯 48–66）

| | VAE | EM |
|---|---|---|
| 共同目的 | 抬 ELBO / 处理隐变量似然 | 同左 |
| $q$ 从哪来 | 神经网络 | 常解析（GMM 责任度等） |
| 怎么优化 | $\phi,\theta$ 联合 SGD | 交替：E 更新 $q$，M 更新 $\theta$ |

| | |
|---|---|
| **困难** | 同时要推断隐变量又要学生成参数 |
| **EM 买到什么** | 在 $q$ 可精确写时，交替优化往往稳定、好分析（GMM、K-means） |
| **VAE 买到什么** | $q$ 可极灵活（深度网），但失去「E 步最优闭式」的保证 |

**K-means 思想实验**：one-hot 编码 + 查表中心 = 极简 AE / 极弱生成模型（只会吐 $K$ 个原型）。  
**现实意义**：说明「离散隐变量 + 码本」合法；也说明**只有码本、没有结构化先验**时生成很差 → 引出 VQ-VAE。

## 6. VQ-VAE（幻灯 67–80）

### 6.1 为何离散？

| | |
|---|---|
| **困难** | 语言/符号天然离散；连续 $z$ 有时后验塌缩、不便当 token |
| **离散 $z$ 买到什么** | 可当符号表；易接 AR/掩码/扩散等「符号序列模型」 |
| **若坚持连续** | 仍可做 VAE；但和 LLM/语音 tokenizer 管线不好对接 |

### 6.2 量化 + 直通梯度

```text
x → Enc → z_e → 最近邻 codebook → z_q → Dec → x′
```

| | |
|---|---|
| **困难** | $\arg\min$ / one-hot **不可微** |
| **直通买到什么** | 前向硬量化（真正离散）；反向假装梯度能过（工程折中） |
| **若不用直通** | 离散采样处梯度断掉，encoder 学不动 |

损失 ≈ 重建 + codebook/commitment（像深度 K-means）。

### 6.3 Tokenizer 的关键限制（课上最重要工程结论）

VQ-VAE 常输出**许多空间位置上的 token**，但训练时的 $p(z)$ 往往只是**逐位置**的。

| | |
|---|---|
| **困难** | 各位置 token **统计上不独立**（图像有结构） |
| **只训重建+码本买到什么** | 好用的离散接口（压缩、表征） |
| **若推理时从 i.i.d. 先验乱采 token** | 解码几乎一定糊/坏——**缺联合分布模型** |

下一步：用自回归 / Masked / 扩散学 token 的联合分布（现代「tokenizer + 先验」分工）。

## 7. 本讲对照表（背这个比背公式有用）

| 步骤 | 目的（人话） |
|---|---|
| 引入 $z$ | 用简单噪声源解释复杂数据 |
| 引入 $q$ / ELBO | 绕过不可算的 $\log p(x)$ |
| 重建项 | 保证 $z$ 还含能还原 $x$ 的信息 |
| KL 到 $p(z)$ | 保证无条件采样时 $z$ 落在「有人教过」的区域 |
| 重参数 | 让「采样」能反向传播 |
| EM | 同一目标，解析 $q$ + 交替优化 |
| VQ | 得到离散 token；联合分布另训 |
