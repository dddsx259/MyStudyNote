## 目录结构

| 路径 | 用途 |
|---|---|
| `Lec/` | lecture notes + 同目录 AI 讲义/目录索引 |
| `Lec/handout/` | 课堂手写 handout (**不** AI 提取) |
| `tut/` | Tutorial 题面 / 官方解答 / 总结 |
| `assignment/` | Homework 题面 / 题目理解 / 解答提示 |
| `docs/` | cache / 结构参考 / 官网 HTML·webarchive |
| `课程信息.md` | 全课唯一课程信息 |
| `cheatsheet.md` | 词条速查 |
| `index.md` | AI md 跳转索引 |
| `readme.md` | 本文件 |

## 产出索引

| 文件 | 原始材料 | 说明 |
|---|---|---|
| `课程信息.md` | lecture notes | 课程信息与评分 |
| `Lec/01-…-目录索引.md` | lecture notes | 全 notes 目录 |
| `Lec/02-…-Ch01-讲义.md` … `06-…-Ch05` | 分章 | Ch.1–5 讲义 |
| `tut/01-tutorial-01-总结.md` | Tutorial 1 | 题意摘要 |
| `assignment/01-homework-01-题目理解.md` | HW1 | 题意 |
| `assignment/01-homework-01-解答.md` | HW1 | 证明思路提示 |

## 使用说明

- 复习优先看 `Lec/*-讲义.md` 与 `cheatsheet.md`
- AI md 与源 PDF 同目录; **无** `notes/` 文件夹
