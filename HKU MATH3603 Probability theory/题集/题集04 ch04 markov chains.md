## 课件证明

### P1. Chapman–Kolmogorov 方程

- **陈述**: **假设** 时齐马尔可夫链; **结论** $p_{ij}^{(m+n)}=\sum_k p_{ik}^{(m)}p_{kj}^{(n)}$, 即 $P^{m+n}=P^m P^n$.
- **证明**: 对中间时刻 $k$ 全概率, 再用 $P(X_{m+n}=j\mid X_m=k)=p_{kj}^{(n)}$.
- **来源**: `Lec/Lec04 probability theory lecture notes Ch04 讲义.md` §4.2

### P2. 分布演化 $\mu_n=\mu_0 P^n$

- **陈述**: **结论** $(\mu_{n+1})_j=\sum_i \mu_n(i)p_{ij}$, 故 $\mu_n=\mu_0 P^n$.
- **证明**: 全概率一步; 归纳.
- **来源**: 同上 §4.2

### P3. 暂态期望访问次数

- **陈述**: **假设** 自 $j$ 出发, $f_{jj}=P_j(T_j^+<\infty)$; **结论** $E_j N_j=1/(1-f_{jj})$.
- **证明**: $N_j$ 为几何型 (每次返回概率 $f_{jj}$), 均值 $1/(1-f_{jj})$.
- **来源**: 同上 §4.4

### P4. 一维随机游走常返 ($p=1/2$)

- **陈述**: **假设** $Z$ 上最近邻, $p=q=1/2$; **结论** 状态 0 常返 ($\sum_n p_{00}^{(2n)}=\infty$).
- **证明**: $p_{00}^{(2n)}\sim 1/\sqrt{\pi n}$, 调和级数型发散.
- **来源**: 同上 §4.5

### P5. 一维随机游走暂态 ($p\neq1/2$)

- **陈述**: **假设** $p\neq1/2$; **结论** 0 暂态.
- **证明**: $4pq<1$, $p_{00}^{(2n)}$ 几何衰减, 级数收敛.
- **来源**: 同上 §4.5

### P6. 高维 Polya 常返性

- **陈述**: 简单对称随机游走: $d=1,2$ 常返, $d\ge3$ 暂态.
- **证明**: 超出本课已授范围; 讲义仅陈述 / 渐近 $n^{-d/2}$ 与 $p$-级数 (未完整证明).
- **来源**: 同上 §4.5

### P7. 极限分布 $\Rightarrow$ 平稳

- **陈述**: **假设** $\lim_n p_{ij}^{(n)}=\pi_j$ 存在; **结论** $\pi=\pi P$, $\sum_j\pi_j=1$.
- **证明**: $p_{ij}^{(n+1)}=\sum_k p_{ik}^{(n)}p_{kj}$, 令 $n\to\infty$ 交换有限和.
- **来源**: 同上 §4.6

### P8. 遍历收敛定理 (Thm. 4.6.7)

- **陈述**: **假设** 链遍历 (不可约 + 正通常返 + 非周期); **结论** 唯一平稳 $\pi_j>0$, $p_{ij}^{(n)}\to\pi_j$, $\pi_j=1/m_j$.
- **证明**: 超出本课已授范围; 讲义仅陈述 / 再生论与耦合思路.
- **来源**: 同上 §4.6

### P9. 两状态平稳分布

- **陈述**: **假设** $P=\begin{pmatrix}\alpha&1-\alpha\\ \beta&1-\beta\end{pmatrix}$; **结论** $\pi_0=\beta/(\beta+1-\alpha)$, $\pi_1=(1-\alpha)/(\beta+1-\alpha)$.
- **证明**: 解 $\pi=\pi P$ 与 $\pi_0+\pi_1=1$.
- **来源**: 同上 §4.6

### P10. 赌徒破产吸收概率

- **陈述**: **假设** 状态 $\{0,\ldots,N\}$, 内部 $p$ 上 $q$ 下, 0/N 吸收; **结论** $u_i=P_i(\text{先达 }N)= \dfrac{1-(q/p)^i}{1-(q/p)^N}$ ($p\neq q$), 或 $i/N$ ($p=q$).
- **证明**: 首步方程 $u_i=p u_{i+1}+q u_{i-1}$, 差分 $\delta_{i+1}=(q/p)\delta_i$, 边界 $u_0=0,u_N=1$.
- **来源**: 同上 §4.7

### P11. 分支过程均值 $EZ_n=\mu^n$

- **陈述**: **假设** Galton–Watson, 后代均值 $\mu$; **结论** $EZ_n=\mu^n$.
- **证明**: $E[Z_n\mid Z_{n-1}]=Z_{n-1}\mu$, 全期望递推.
- **来源**: 同上 §4.9–4.11

### P12. PGF 独立和

- **陈述**: **假设** $S_N=\sum_{i=1}^N Y_i$, $N\perp\!\!\!\perp Y_i$; **结论** $G_{S_N}(s)=G_N(G_Y(s))$.
- **证明**: $E[s^{S_N}\mid N]=G_Y(s)^N$, 再对 $N$ 取期望.
- **来源**: 同上 §4.9–4.11

## 练习题

### 1. 两状态链

- **题目**: 给定 2 状态转移矩阵, 求 $P^n$, 平稳 $\pi=\pi P$, 与极限对照.
- **思路**: 矩阵幂或特征值; 解线性方程组.
- **来源**: Lec Ch04 例题要点

### 2. 赌徒破产

- **题目**: 随机游走带 absorbing 边界, 求从 $i$ 被吸收概率.
- **思路**: 首步分析差分方程 + 边界.
- **来源**: Lec Ch04 例题要点 (Gambler's Ruin)

### 3. 基本矩阵

- **题目**: 暂态集 $T$, 求期望占用 $G_T=(I-Q)^{-1}$.
- **思路**: 吸收链分块, 读矩阵元素.
- **来源**: Lec Ch04 例题要点

### 4. 分支过程灭绝

- **题目**: 给定后代 PGF $G(s)$, 求灭绝概率 $\eta$.
- **思路**: $y=G(s)$ 与 $y=s$ 在 $[0,1)$ 最小交点.
- **来源**: Lec Ch04 例题要点
