## 材料形态

本课典型材料:

1. **一份大的 lecture notes PDF** (全书式讲义) → 放在 `Lec/`; AI 目录索引与分章讲义与该 PDF **同目录**
2. **每节课的 handout** (多为手写扫描) → 只归位到 `Lec/handout/`, **不要** AI 提取/生成讲义

HKU MATH3603 Probability theory/

    ├── 02-…-Ch01-讲义.md

| 路径 | 用途 |
|---|---|
| `Lec/*.pdf` (非 handout) | 主 lecture notes 等可排版材料; 可生成同目录讲义 |
| `Lec/handout/` | **手写** in-class notes / 课堂 handout; **仅整理归位**, 不生成 `*-讲义.md` |
| `docs/` | cache / 本结构参考 / 官网 HTML·webarchive |
| `课程信息.md` | 评分/教材/政策 (可从大 notes 首页 + 官网合并) |

**不要**创建 `notes/` 目录. meta 文件一律在 `docs/`.

## 手写 handout 规则 (强制)

识别启发式 (满足任一即可归入 `Lec/handout/`):

- 文件名含 `in-class`, `in class`, `handwritten`, `手写`
- 或扫描件/图片型 PDF, 内容为课堂板书/手写笔记
- 或用户标明「handout / 手写 / 不整理」

处理:

1. 移入 `Lec/handout/`, 命名 `{NN}-{title-slug}.pdf`
2. cache 写入该源, `outputs: []`, `skip_reason: handwritten_handout`
3. **禁止**生成讲义 / 目录索引 / 题目理解
4. readme 索引可列出路径, 说明为「手写 handout, 未提取」

若日后出现**可排版/电子版**课堂 handout 且用户要求整理, 再按普通 Lec 材料生成同目录讲义 (以 `handout/` 文件夹 + skip_reason 为准).

## 大 lecture notes

- 视为大部头: 先目录索引; 分章讲义需确认范围 (或沿用已 `sections_done`)
- 产出一律在 `Lec/`, 与 PDF 并列
- 课堂 handout **不是**大 notes 的替代讲义来源
