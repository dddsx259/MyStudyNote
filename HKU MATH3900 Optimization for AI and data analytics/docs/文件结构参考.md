## 材料形态

每讲通常有:

1. **Handout** → `Lec/handout/Handout{NN} {topic} handout.pdf` (讲次号与 slides 对齐; 空格分词)
2. **Slides / slides-long** → `Lec/Lec{NN} {topic} slides.pdf` 与 `Lec/Lec{NN} {topic} slides long.pdf` (**共享 Lec{NN}**)
3. **Optional 教材** → `Lec/textbook/` (独立编号)

AI 讲义与对应源 PDF 同目录.

## 规则摘要

| 材料 | 位置 | 编号 |
|---|---|---|
| handout | `Lec/handout/` | 按讲次; 与 slides 同号 |
| slides + long | `Lec/` | **共享**讲次 `NN` |
| optional textbook | `Lec/textbook/` | 夹内独立 `01`, `02`, … |
| **题集** | `题集/` | 与 slides 讲次对齐; 见 course-learning `reference-problem-set.md` |
| **Moodle/课上公告** | `课程信息.md` →「Moodle 公告归档」 | **全部**录入 (含历史); 新公告倒序置顶 |
