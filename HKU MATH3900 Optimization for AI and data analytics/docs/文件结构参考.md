# MATH3900 文件结构参考

> 本课覆盖父目录 `My Study Notes/文件结构参考.md`. 本文件路径: `docs/文件结构参考.md`.

---

## 材料形态

每讲通常有:

1. **Handout** → `Lec/handout/{NN}-{topic}-handout.pdf` (讲次号与 slides 对齐)
2. **Slides / slides-long** → `Lec/{NN}-{topic}-slides.pdf` 与 `Lec/{NN}-{topic}-slides-long.pdf` (**共享 NN**)
3. **Optional 教材** → `Lec/textbook/` (独立编号)

AI 讲义与对应源 PDF 同目录.

## 规则摘要

| 材料 | 位置 | 编号 |
|---|---|---|
| handout | `Lec/handout/` | 按讲次; 与 slides 同号 |
| slides + long | `Lec/` | **共享**讲次 `NN` |
| optional textbook | `Lec/textbook/` | 夹内独立 `01`, `02`, … |
