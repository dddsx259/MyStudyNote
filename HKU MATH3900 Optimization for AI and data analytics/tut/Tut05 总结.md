## 1. True / False

设 $P_C$ 为到非空闭凸集 $C$ 的欧氏投影.

| | 判定 | 要点 |
|---|---|---|
| (a) | **False** | 单位圆盘边界点 $(1,0)$, $s=(0,1)$: $\|x+ts\|^2=1+t^2>1$, 直线段立刻穿出; 切向 ≠ 可行方向 (讲义用直线段定义) |
| (b) | **True** | $u\in C\Rightarrow P_C(u)=u$; 非扩张 $\|P_C(v)-P_C(u)\|\le\|v-u\|$ |
| (c) | **False** | 仅凸可行集不够; 反例 $C=[-1,1]$, $f=-x^2$, $x^\star=0$ 满足 VI 但非全局极小. **还需 $f$ 凸** 才充分 |
| (d) | **False** | 投影不必保平均; 反例 $C=[0,1]$, $u=0$, $v=2$ |

## 2. 单纯形型多面体上的二次目标

$$
\min_{x\in C} f(x)=\tfrac12\bigl((x_1-3)^2+(x_2-1)^2\bigr),\quad
C=\{x:x_1\ge0,\,x_2\ge0,\,x_1+x_2\le2\},\quad x^\star=(2,0)^T.
$$

### (a) 约束与主动集

$g_1=-x_1$, $g_2=-x_2$, $g_3=x_1+x_2-2$. 于 $x^\star$: $A(x^\star)=\{2,3\}$.

### (b) 可行方向

$s=(s_1,s_2)$ 可行 $\Leftrightarrow$ $s_2\ge0$ 且 $s_1+s_2\le0$ (保 $x_2=0$ 与 $x_1+x_2=2$ 边界内侧短线段; $x_1\ge0$ 因起点 $x_1=2$ 自动短步可保).

### (c) 一阶条件 ⇒ 唯一全局极小

$\nabla f(x)= (x_1-3,\,x_2-1)^T$, 故 $\nabla f(x^\star)=(-1,-1)^T\ne0$.

对任意 $v\in C$: 需 $\nabla f(x^\star)^T(v-x^\star)\ge0$. 结合凸二次 (强凸) 得唯一全局极小.

普通梯度步 $x^\star-\alpha\nabla f(x^\star)=(2+\alpha,\alpha)^T$ 立即离开 $C$ (第二坐标与 $x_1+x_2$ 约束), 故需投影 / 投影梯度.

## 3. 半空间投影

$C=\{x:x_1+2x_2\le2\}$, $u=(2,2)^T$, $a=(1,2)^T$. 刻画: $z=P_C(u)\Leftrightarrow (u-z)^T(v-z)\le0$ $\forall v\in C$.

### (a)

$\hat z=(0,1)$ 可行但取 $v=(1,1/2)$ 破坏刻画 ⇒ 非投影.

### (b)

边界候选 $z=u-ta$, $z_1+2z_2=2$ ⇒ 解得 $t=4/5$, $z=(6/5,2/5)^T$; 验证刻画; $\|u-z\|^2=16/5$.

### (c)

展开 $\|u-v\|^2=\|u-z\|^2+\|v-z\|^2-2(u-z)^T(v-z)$ 并用刻画得
$\|u-v\|^2\ge 16/5+\|v-z\|^2$, 故 $z$ 唯一最近.

## 4. 切向 / 法向扰动与非扩张紧性

$d_T=(1/5,-1/10)^T$ (切向), $d_N=(1/10,1/5)^T$ (法向比例于 $a$).

- (a) $\|d_T\|=\|d_N\|=\sqrt{1/20}$; 非扩张 ⇒ 投影变化 $\le$ 该范数.
- (b) $P_C(u+d_T)=z+d_T$; $P_C(u+d_N)=z$ (法向扰动被「压回」边界).
- (c) 切向扰动使界**取等**; 法向扰动投影不动, 界松. 几何: 边界法向为 $a$.
