# 河套学院-HKU 连培信息与门槛

> 整理日期: 2026-08-23
> 面向对象: 香港大学 BEng CS 本科生(大三, 方向 AI/ML/TCS, 辅修数学)
> 关联文件: `学业档案摘要.md` / `对话纪要与选课规划.md`
> 说明: 本文档聚焦「深圳河套学院」与香港大学的博士联合培养, 非内蒙古「河套学院」, 两者是完全不同的机构, 切勿混淆(见文末附录)。

## 0. 一句话结论(先读这个)

1. 你问的「河套学院-HKU 连培」= **深圳河套学院(SLAI)** 与 **香港大学** 的博士联合培养项目。
2. 深圳河套学院**只招博士生**, 没有本科连培项目; 它是 2025 年 2 月才获教育部批复成立的 AI 拔尖创新人才培养试验区。
3. 学院自身**不设固定 GPA 门槛**, 靠「选拔营」(笔试 + 工作坊 + 面试)综合遴选; 但香港大学联合培养博士的惯例门槛是 **本科起点 GPA ≥ 3.6/4.0**(参考值)。
4. 对港大学生最关键的一点: 河套学院是「**联合培养**」, 学生**必须先被参建高校(如港大)录取为博士**, 再到河套学院报到。所以你的第一步是拿到港大 PhD offer。

## 2. 与香港大学的联合培养模式

核心机制是「**跨境联合培养 + 双导师/多导师**」:

- 学生先被**参建高校(如港大)录取为博士**(直博/硕转博/普博均可)。
- 再到河套学院报到, 在河套合作区开展科研, 由港大导师与河套学院双聘教授共同指导。
- 学位最终由**参建高校(港大)颁发**, 河套学院提供算力、产业场景、国际化平台。
- 教学与选拔沿用香港惯例, 全英文, 全球选聘师生。

对港大本科生而言, 这条路径的实际链条是:

```
港大 PhD offer(直博/普博) → 被提名或自主报名河套学院选拔营 → 通过选拔 → 联合培养(港大学位 + 河套资源)
```

## 4. 门槛与遴选标准(重点)

### 4.1 官方遴选标准(深圳河套学院官网)

学院**不设统一固定 GPA 门槛**, 采用选拔营综合考核, 核心考察方向:

- **基础能力**: 数理思维, 代码能力
- **应用能力**: 算法设计, 工程实践, 用多学科知识解决复杂实际问题
- **潜质**: 颠覆性思维, 提出关键科学问题的能力, 领导力, 团队协调力
- **国际视野**: 了解国际 AI 研究现状与创新方向

选拔形式: **笔试 + 工作坊 + 面试**(学院教授 + 行业专家共同参与)。

### 4.2 关于 GPA 的具体要求

这是最需要说清楚的部分, 分三层:

1. **学院层面**: 无固定 GPA 数字门槛, 弹性遴选。
2. **报名层面**: **本科阶段累计 GPA 为必填项**, 需如实填写并注明绩点评定标准(如 `3.4/4.0`, `3.8/4.3`, 或 `80/100`), 需与成绩单原件一致。
3. **香港大学联合培养惯例(参考值)**:
   - 本科起点(直博)申请香港大学: GPA 须达 **3.6/4.0**
   - 硕士起点: 本科及硕士 GPA 均须达 **3.0/4.0**

> 关于 `3.6/4.0` 的出处: 该数字来自「深圳湾实验室-HKU 联合培养博士」招生简章的明文要求(深圳湾实验室 SZBL 是河套合作区内另一家与港大联合培养博士的机构)。深圳河套学院官网本身未写死这个数字, 但作为港大联合培养的同类项目, 它是最可靠的参考基准。

### 4.3 对你(港大 CS)的 GPA 换算提醒

香港大学用 letter grade + 4.3 scale(CGPA), 与内地 4.0 scale 不同。报名时须:

- 按成绩单真实填写你的 CGPA(如港大 4.3 制), 并注明 scale。
- 港大 4.3 制与 4.0 制不能直接等同, 若官方要求 4.0 制, 需按港大官方 conversion 表换算, 或直接提供 letter grade + 成绩单原件说明。

> 行动项: 提前查清港大 CGPA 到 4.0 scale 的官方换算口径(教务处/Registry), 避免申请时被 scale 问题卡住。

## 6. 奖学金与待遇标准

### 6.1 一句话结论

河套学院**不设统一固定薪资**, 而是分层激励: 顶尖入选者(深荐计划-深源英才赛道)可拿到**对标香港政府博士奖学金(HKPFS)**级别的待遇, 最高**连续 4 年**。

### 6.2 河套学院官方披露的待遇

**深荐计划 · 深源英才赛道**(面向顶尖博士生, 整体深荐计划预计 120 人):

| 项目 | 内容 |
|------|------|
| 顶格待遇 | 最高**连续 4 年**对标 HKPFS 级别的高额奖学金 |
| 续得条件 | 学业达标(课程平均 **GPA 保持在 B 及以上**) + 科研表现稳健(顺利通过每年年度学术评估) |
| 附加资源 | 充足算力资源, 全方位生活保障 |

**深荐计划 · 创业星火赛道**(预计 10 人):

| 项目 | 内容 |
|------|------|
| 物质保障 | 生活补贴 + 顶配算力 + 全方位生活保障(未公布具体数字) |
| 创业支持 | 创业启动包 + 科创孵化空间 + AI 实验室 + 智慧教室 |
| 导师配置 | 37 所高校联动 + 全球顶尖 AI 科学家 + 产业资深导师 |

### 6.3 HKPFS 作为「对标基准」的具体金额

HKPFS(Hong Kong PhD Fellowship Scheme)由香港研究资助局(RGC)设立, 河套学院以其为「对标」基准:

| 项目 | 金额(2026/27 学年) |
|------|------|
| 奖学金 | 每年 **港币 344,400 元**(约 32 万人民币, 汇率浮动) |
| 会议及研究交通津贴 | 每年港币 14,400 元 |
| 资助期 | 3 年(河套学院可达 4 年) |
| 名额 | 每年 400 人 |

> 注: 官方不同页面出现 340,800 / 344,400 两个数字, 是不同学年差异; 344,400 为 2026/27 最新值。河套学院只承诺「对标」这个级别, 未公布等值的人民币具体数字。

### 6.4 需要自行核实的关键点

1. **钱由谁发、能否叠加**: 连培学生学位由港大颁发, 港大本身有研究生奖学金(PGS)或 HKPFS; 河套学院「对标 HKPFS」是**额外激励**还是**替代**, 官方未讲清, 需直接问 `admission@slai.edu.cn`。
2. **普通选拔营(非深荐计划)入选者的待遇**未明确披露, 公开信息只有「深荐计划」的待遇。
3. **别与「博士后」混淆**: 深圳市博士后在站生活补助(36 万/60 万等)是**博士后**, 不是博士生连培。
