## 名词

+ **Field** / **域**:
    + 满足 (A1)–(A4), (M1)–(M4), (D) 的代数结构
+ **Ordered field** / **有序域**:
    + 带全序 $\le$ 满足 (O1)–(O5) 的域
+ **Upper bound / Lower bound** / **上界/下界**:
    + $M$ 为上界: $\forall x\in S,\ x\le M$; 下界对偶
+ **Maximum / Minimum** / **最大值/最小值**:
    + 必须在 $S$ 内且界住全体元素
+ **Supremum / Infimum** / **上确界/下确界**:
    + sup: 最小上界; inf: 最大下界; 可以不在 $S$ 内
+ **Completeness axiom** / **完备性公理**:
    + 非空有上界子集必有 sup; $\mathbb{R}$ 为 complete ordered field
+ **Dense** / **稠密**:
    + $\mathbb{Q}$ 在 $\mathbb{R}$ 中: 任意 $a<b$ 存在有理数 $r$ 使 $a<r<b$
+ **Countable / Uncountable** / **可数/不可数**:
    + 可数: 有限或与 $\mathbb{N}$ 双射; 否则不可数

## 公式

+ **Supremum criterion** / **上确界判别**:
    + $u=\sup S \iff u$ 为上界且 $\forall\epsilon>0,\ \exists x\in S,\ u-x<\epsilon$

## 定理

+ **Theorem 3.3 (Sup criterion)**:
    + 见上
+ **Corollary 4.6 (Density of Q)**:
    + $a<b \Rightarrow \exists r\in\mathbb{Q},\ a<r<b$
+ **Theorem 4.8–4.9 ($\sqrt{2}$)**:
    + 无有理数平方为 2; $\sqrt{2}=\sup\{y\in\mathbb{R}: y^2<2\}\notin\mathbb{Q}$
+ **Theorem 5.5 (Nested intervals)**:
    + 闭区间 $[a_n,b_n]$ 嵌套 $\Rightarrow \bigcap\ne\emptyset$
+ **Theorem 5.8**:
    + $\mathbb{R}$ 不可数
+ **Theorem 5.11**:
    + $\mathbb{Q}$ 可数
