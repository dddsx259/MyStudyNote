## 课件证明

### P1. $\sqrt{2}$ 无理 (反证)

- **陈述**: $\sqrt{2}$ 不是有理数.
- **证明**: 设 $\sqrt{2}=p/q$, $p,q\in\mathbb{Z}^+$, $\gcd(p,q)=1$. 平方得 $p^2=2q^2$, 故 $p^2$ 偶, $p$ 偶. 令 $p=2r$, 则 $q^2=2r^2$, $q$ 偶, 与 $\gcd(p,q)=1$ 矛盾.
- **来源**: Lec02 Part 4 / `Lec02 Numbers 讲义.md`

### P2. 二次方程求根公式 (配方法)

- **陈述**: $ax^2+bx+c=0$ ($a\neq 0$) 的解为 $x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}$.
- **证明**: $ax^2+bx+c=a\bigl(x+\frac{b}{2a}\bigr)^2-\frac{b^2-4ac}{4a}$. 令其为 0 移项开方即得.
- **来源**: Lec02 Part 4 证明思路

### P3. 对数乘法化为加法

- **陈述**: 对 $b>0$, $b\neq 1$ 与 $x,y>0$, $\log_b(xy)=\log_b x+\log_b y$.
- **证明**: 设 $\log_b x=u$, $\log_b y=v$, 则 $x=b^u$, $y=b^v$, $xy=b^{u+v}$, 故 $\log_b(xy)=u+v$.
- **来源**: Lec02 Part 5

### P4. 自然数与完全平方数集合等势

- **陈述**: $n\mapsto n^2$ 给出 $\mathbb{N}\to\{1,4,9,\ldots\}$ 的双射, 故真子集可与原集合 **等势**.
- **证明**: 单射: $n\neq m\Rightarrow n^2\neq m^2$. 满射: 每个完全平方 $k^2$ 的原像为 $k$. 故双射.
- **来源**: Lec04 Part 1 伽利略悖论

### P5. 希尔伯特旅馆: 客满仍可接新客

- **陈述**: 可数无穷多房间且均已住满时, 仍可再接待一位客人.
- **证明**: 令原 $n$ 号客移至 $n+1$ 号 ($n\mapsto n+1$ 为 $\mathbb{N}\to\{2,3,\ldots\}$ 的双射), 则 $1$ 号空出给新客. 故 $\aleph_0+1=\aleph_0$ 在可数情形成立.
- **来源**: Lec04 Part 1

### P6. 素数无穷 (欧几里得)

- **陈述**: 素数有无穷多个.
- **证明**: 设全体素数为 $p_1,\ldots,p_k$. 令 $N=p_1\cdots p_k+1>1$, 取素因子 $q$. 若 $q=p_i$, 则 $p_i\mid N$ 且 $p_i\mid p_1\cdots p_k$, 故 $p_i\mid 1$, 矛盾. 故还有新素数.
- **来源**: Lec04 Part 2 定理

### P7. 柯尼斯堡七桥不可一笔画

- **陈述**: 一次走遍七座桥且每桥恰走一次不可能.
- **证明**: 把陆地作顶点, 桥作边. Euler 路径存在 $\Leftrightarrow$ 奇度顶点数为 0 或 2 (中间顶点进出成对, 度数为偶). 柯尼斯堡图有 **四个** 奇度顶点, 故无 Euler 路径.
- **来源**: Lec04 Part 3

### P8. 囚徒困境: $(D,D)$ 为唯一纯策略纳什均衡

- **陈述**: 在讲义典型收益矩阵下, $(D,D)$ 是唯一纯策略 NE, 但 $(C,C)$ 帕累托优于 $(D,D)$.
- **证明**: 无论对方选 C 或 D, 己方选 D 的收益 ($5$ 或 $1$) 严格大于选 C ($3$ 或 $0$). 故 D 为严格占优, $(D,D)$ 为唯一纯 NE. 而 $(C,C)$ 各得 $3>1$.
- **来源**: Lec04 Part 4 博弈论

### P9. 巴比伦半弦长 (勾股 + $\pi=3$)

- **陈述**: 直径 60 ($\pi=3$ 故 $r=30$), 圆心到弦垂线长 2, 则半弦长 $x=\sqrt{896}$.
- **证明**: 直角三角形 $x^2+2^2=r^2=30^2=900$, 故 $x=\sqrt{900-4}=\sqrt{896}$.
- **来源**: Lec06 巴比伦弦长例 / `Lec06 Student Version 讲义.md`
