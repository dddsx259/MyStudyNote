## Lec/ 子文件夹命名

**每讲一个文件夹**, 该讲相关文件全部放入此文件夹, 不再平铺在 `Lec/` 根下.

格式: **`Lec{NN}-{主题}/`**

| 部分 | 规则 |
|---|---|
| `{NN}` | 两位讲次编号 `01`, `02`, … (与课程 Lec 顺序一致) |
| `{主题}` | 英文或拼音短标签, 空格用 `-` 连接; 可从 syllabus 主题截取 |

示例:

```text
Lec/
├── Lec01-Introduction/
│   ├── 01-slides-overview-2026.pdf
│   ├── 02-reading-….pdf
│   └── 01-Lec01-Introduction-讲义.md    # 与课件同夹
├── Lec02-Numbers/
│   └── …
└── Lec00-Unsorted-Readings/             # 无法归讲次时
```

- 一次课有多份 PDF/图片/链接说明 → 全部留在同一 `Lec{NN}-{主题}/` 内
- agent 生成讲义时, stem 取 **子文件夹名** (如 `Lec01-Introduction`), 产出写在**该子文件夹内**

## tut/ 子文件夹命名

**每次 tutorial 一个文件夹**, 且 **必须包含日期** (必要时加时间).

格式 (推荐): **`{YYYY-MM-DD}-tut{NN}/`**  
或: **`{YYYY-MM-DD}-{HHmm}-tut{NN}/`** (同一天有多场时加时间)

| 部分 | 规则 |
|---|---|
| `{YYYY-MM-DD}` | Tutorial 日期 (**必填**) |
| `{HHmm}` | 24 小时制开始时间 (可选) |
| `{NN}` | 该学期第几次 tut `01`, `02`, … |

- 用户手写 prep / 课堂笔记 → 放在对应 tut 子文件夹内
- agent 生成 tut 总结时, stem 用 **子文件夹名**, md 写在**该子文件夹内**

## GP/ 与 essay/

### GP/

```text
GP/
├── brief/
├── draft/
├── final/
└── feedback/
```

也可按 milestone 分子文件夹. 新建 GP 任务时在 readme 索引一行. AI 总结/修改意见放在对应子目录内.

### essay/

```text
essay/
├── prompt/
├── outline.md
├── draft-v1.md
└── final/
```

改稿意见由 agent **只给评论不改源文件**; 可选存档同目录 `{NN}-{稿名}-修改意见.md`.

## 产出路径 (与源同目录)

| 类型 | 路径模式 |
|---|---|
| 课程信息 | `课程信息.md` (课程根; 全课唯一) |
| 讲义 | `Lec/Lec{NN}-{主题}/{nn}-Lec{NN}-{主题}-讲义.md` |
| Tutorial 总结 | `tut/{date}-tut{NN}/{nn}-{tut文件夹名}-总结.md` |
| GP | `GP/…/{nn}-{stem}-总结.md` 或 `-修改意见.md` |
| Essay | `essay/…/{nn}-{stem}-修改意见.md` 或 `-翻译总结.md` |
| 其他 reading 总结 | 优先放在所属 `Lec{NN}-*/` 内; 无法归类可 `other/` |

- `{nn}`: 在同一文件夹内编号
- `{Lec文件夹名}` / `{tut文件夹名}`: 与原始子文件夹名一致

## Stray 文件归位 (本课)

| 材料类型 | 移至 |
|---|---|
| 某一讲 slides/reading | 对应 `Lec/Lec{NN}-{主题}/` (新建文件夹若不存在) |
| tutorial 材料 | `tut/{YYYY-MM-DD}-tut{NN}/` (**须含日期**) |
| group project | `GP/` (或子目录) |
| essay 相关 | `essay/` |
| syllabus / 全课 intro | `Lec/Lec01-Introduction/` 等; 课程信息写入 `课程信息.md`; 官网 HTML 放课程根并合并 |
| 无法判断 | 暂放 `Lec/Lec00-Unsorted/` 并在 readme 注明 |

## 扫描说明

- agent 解析结构时: **本文件 > 父目录 `文件结构参考.md` > 内置默认**
- 发现 `Lec/` 根下 stray PDF → 移入合适 `Lec{NN}-*/` 或建 `Lec00-Unsorted/`
- 发现 `tut/` 根下 stray 文件 → 移入含日期的 tut 子文件夹
- **文件名混乱** → 读内容后按「文件命名」更正
- 工作区根 `HKU courses todo.md`: 本课**当前可做**学生任务; **讲义入库后按章节拆 Read**; 已完成块置顶
- 官网 HTML: 放本课 `docs/HKU CCST5037.html` 或 `docs/*.webarchive` (若有)

## 文件命名 (本课)

| 位置 | 文件夹 | 文件 (示例) |
|---|---|---|
| Lec | `Lec{NN}-{主题}/` | `{nn}-{title-slug}.pdf` |
| tut | `{YYYY-MM-DD}-tut{NN}/` | `{nn}-worksheet-….pdf` |
| GP | `GP/draft/` 等 | `{nn}-gp-….pdf` |
| essay | `essay/` | `{nn}-essay-….md` |

**强制**: 同一文件夹内文件必须有两位序号前缀; 主名以文档标题/主题 slug 为准. 过泛的课程总标题不可单独作为文件名.
