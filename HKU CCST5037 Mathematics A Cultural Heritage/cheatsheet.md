## 名词

+ **Course Learning Outcomes (CLO)** / **课程学习成果**:
    + 美与用与「道」; 数学作为人类文化; 与其他文化领域互动; 文明发展中的角色
+ **Central theme** / **中心主题**:
    + Group essay 须有贯穿全文的清晰论点 (非单纯书评)
+ **Explicit connection** / **显式关联** (Assignment 2):
    + 文章本身须明确提到数学; 仅含数字/数据或读者自行联想不算
+ **Way of Mathematics** / **数学之道**:
    + 概括 (generalization) 与抽象 (abstraction); 把问题搬到更易处理的数学世界
+ **Correspondence / one-to-one matching** / **一一对应**:
    + 「三」的抽象内核: 与具体苹果/羊无关的配对
+ **Positional number system** / **进位制记数**:
    + 符号兼有绝对值与位置值; 对比罗马非进位制
+ **Sexagesimal (hexagesimal)** / **六十进制**:
    + 巴比伦记数; 今仍见于时间/角度
+ **Commensurable** / **可通约**:
    + 两量存在公共度量且皆为其整数倍; Pythagoreans 曾信一切量可通约
+ **Potential vs actual infinity** / **潜无穷 vs 实无穷**:
    + 任意大的有限 vs 「全体」无穷集合
+ **Cardinality** / **势 / 基数**:
    + 两集合存在一一对应则等势 (Cantor)
+ **Topology** / **拓扑**:
    + 允许连续形变下不变的形状性质 (洞的个数等); 杯与甜甜圈
+ **Nash equilibrium** / **纳什均衡**:
    + 无人可单方面改善自身收益的策略组合
+ **Prisoner's dilemma** / **囚徒困境**:
    + 个体理性导致集体更差结果的博弈结构
+ **Quadrivium** / **四艺**:
    + Arithmetic, Geometry, Astronomy, Music
+ **Confucian-heritage culture (CHC) paradox** / **儒家文化圈学习悖论**:
    + 「死记印象」与高成就/意义策略自报之间的张力
+ **Axiomatic–deductive vs pragmatic** / **公理演绎 vs 实用程序**:
    + 希腊 *Elements* 风格 vs 问题—解法传统 (如《九章》)
+ **Parallel postulate / Playfair's axiom** / **平行公设**:
    + 过线外一点恰有一条平行线; 第五公设等价表述之一
+ **Non-Euclidean geometry** / **非欧几何**:
    + Hyperbolic (至少两条平行线) / Elliptic (无平行线)
+ **Platonism (mathematical realism)** / **柏拉图主义**:
    + 数学对象独立存在; 真理被发现
+ **Logicism** / **逻辑主义**:
    + 数学是逻辑的延伸 (Frege, Russell, Whitehead)
+ **Formalism** / **形式主义**:
    + 数学作为严格符号推演; Hilbert 纲领
+ **Russell's paradox** / **罗素悖论**:
    + $R=\{x:x\notin x\}$ 导致矛盾; 冲击素朴集合论
+ **Hilbert's program** / **希尔伯特纲领**:
    + 形式化, 一致性, 完备性, 判定算法等目标
+ **Incompleteness theorems** / **不完备定理** (Gödel):
    + 足够强的一致形式系统中存在真而不可证命题 (细节见课件)
+ **Straightedge-and-compass construction** / **尺规作图**:
    + 三大古典问题; 不可能性结果 (Wantzel, Lindemann)
+ **Four colour theorem** / **四色定理**:
    + 地图至多四色; 1976 计算机辅助证明
+ **Linear perspective** / **线性透视**:
    + 灭点与尺度; Brunelleschi / Renaissance 绘画
+ **Anamorphosis** / **变形透视**:
    + 需特定视角才可读的图像 (如 Holbein *Ambassadors*)
+ **Palindrome** / **回文**:
    + 正反相同的词/数/诗行结构
+ **Public-key cryptography / RSA** / **公钥密码 / RSA**:
    + 乘大素数易, 分解难; 数论的现代社会应用
+ **Operations research** / **运筹学**:
    + 课件引 Clarke: 不战而胜的艺术

## 公式

+ **勾股**: $a^2 + b^2 = c^2$
+ **$\sqrt{2}$ 无理 (反证思路)**: 若 $\sqrt{2}=m/n$ 既约, 则 $m,n$ 皆偶, 矛盾
+ **对数**: 若 $10^b = x$ 则 $\log x = b$; $10^a 10^b = 10^{a+b}$
+ **素数计数 (课件级)**: $\#\{p\le N\}/N \approx 1/\ln N$
+ **Fermat**: $n>2$ 时 $x^n+y^n=z^n$ 无正整数解
+ **罗素**: $R=\{x:x\notin x\}$, $R\in R \Leftrightarrow R\notin R$

## 定理

+ **勾股定理** (Euclid I.47; 跨文化表述多样)
+ **Fermat's Last Theorem** (Wiles 1995)
+ **Four Colour Theorem** (Appel–Haken 1976)
+ **尺规三大作图不可能性** (Wantzel; Lindemann 等)
+ **Gödel 不完备** (真 vs 可证可能分离)
