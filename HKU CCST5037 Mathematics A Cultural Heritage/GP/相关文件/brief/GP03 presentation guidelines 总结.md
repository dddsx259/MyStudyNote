# Presentation Guidelines for the Group Project — 总结

- **来源**: `GP/brief/GP03 presentation guidelines.pdf` (2 页)
- **课程**: CCST5037; 评分细则另见 `GP02 presentation grade descriptors.pdf`

## 形式

| 项 | 规定 |
|---|---|
| 着装 | 不必 formal; 不考核着装 |
| 听众 | 全班同学 + 老师; **勿假设**听众已有高深数学背景 |
| 提示卡 | 可用纸卡/手机笔记, 但勿低头念稿 |
| 时长 | **12 min** 陈述 + **3 min** Q&A; 超时可能被切断 |
| 迟到 | presentation 当天迟到: **扣 5/15** |
| 分工 | 每人须开口; 尽量均分 |
| 视频 | 以自己讲为主; 若必须放视频 ≤ **1 min** |

## 提交

- 格式: `ppt` / `pptx` / `pdf`
- **截止**: Moodle 上传 **2026-11-01 (Sun) 16:55** (严格, 为公平)
- 迟交: **5 分起** + 之后每天 **0.5** (计至 presentation 日). 例: 晚一周 ≈ 5+3.5=8.5 分惩罚

## 评分

- 看 content 与 fluency/clarity/coherence; 细则见 Moodle grade descriptor (`GP02 presentation grade descriptors.pdf`)
