## 子分类表 (固定)

`### COMP3230 …` 下按此顺序用 `####`:

| 顺序 | `####` | 放什么 | 稳定键 |
|---|---|---|---|
| 1 | **Lec** | slides/讲义; **父条 `Read:Lec{NN}`**, 子条对齐 OSTEP | `Read:Lec*`, `Read:OSTEP-Ch*` |
| 2 | **Tutorials** | Tut 对照 | `Tut{n}-…` |
| 3 | **Assignments** | **PS + PA + MiniLab 全部**; 键名仍写具体类型 | `PS{n}` / `PA{n}` / `MiniLab{n}` / `ML{n}-*` |
| 4 | **Exams** | Final 备考等; **无假 due** | `Final`, `Final-KP` … |

- **不设 HandCS** (Final open-book).
- 禁止再拆 Problem Sets / Programming Assignments / Mini-Labs 为独立 `####`.
- 禁止 OSTEP 与 Lec 平铺为同级父条; OSTEP **一章一条**, 不拆 part.

## 命名与 scope

- 做题条文末 `[scope: Lec… / OSTEP Ch.…]`.
- Tut 有编号题 → `Tut{n}-Q{k}` 一题一条; 无编号按主题块.
- 已知任务一律入 todo; **不知 DDL 不写 DDL**.

## 用户新信息 → 双写 (必须)

1. 改 `HKU courses todo.md` (本课节 + 文首总览若有日期).
2. 本文「信息归档」倒序追加 (日期 / 摘要 / 对 todo 影响); 必要时改上方快照.
3. 写入 `HKU COMP3230 Principles of operating systems/课程信息.md` → Moodle 公告归档.
